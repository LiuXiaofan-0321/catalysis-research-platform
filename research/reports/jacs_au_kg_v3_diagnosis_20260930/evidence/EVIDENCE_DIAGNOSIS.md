# KG-v3 证据和真实提示审查

审查日：2026-09-30。只读分析已完成的 9 条主轨迹和最终证据池，复算训练域上的公式有限性；没有新 LLM 调用、没有拟合预测器、没有改变科学结果。详见 `audit_evidence.json` 和可复算脚本 `audit_evidence.py`。

Agent 统计含一次结构化输出修复，共 10 次调用；其余各 9 次。所有调用结束原因是 `stop`，没有 `length` 截断。因此现在证据不支持“输出 token 上限截断导致 RAG/KG 差”；低推理配置与长上下文的交互需要另做实验。

### 1. RAG 很大程度上在重复同一篇文献，并未随反馈补知识

最终池有 23 条 RAG、4 篇文献，其中 19/23（82.6%）来自 `PMC6161062`。KG 有 6 条机制、3 篇文献。每个非 Agent 模式全部 9 轮的证据成员集合完全一样；query 只改变排列顺序。没有任何片段因预算而跳过。

固定池是明确记录的协议限制，不能称为动态知识检索。候选提出的“counterexample/alternative mechanism”查询未检索到新论文；模型被同一套转动/平动/占据体积论述持续牵引。这个设计可以测知识组织效果，不能充分测跨轮主动补证据能力。

### 2. 六条 KG 原句已在 RAG 里，当前新增的是组织与代理映射

逐条规范化文字匹配，6/6 KG 原句均包含于已有 RAG 文本。机制为 `mfi_fau_rotation`、`cavity_rotation`、`translation_rotation`、`mfi_fau_entropy`、`rrho_mobility`、`cage_rotational_equilibrium`。当前不能把 KG 模式描述为获得了六条 RAG 不知道的科学知识。

每个机制均为独立的两节点、一条边；节点 ID 用各自机制 ID 构造，没有共享实体，也没有连接两篇文献的科学推理链。V3 已合理禁止不可靠的跨论文跳跃，不过它的实验角色更接近“六张有来源、条件和代理变量的机制卡”，距离可执行、多步 KG 推理还有差距。

“平铺对照”保留了所有 membership 和 fact IDs，只改序列化组织。它可比较这两种序列化，无法单独证明完整科学图推理的收益。

### 3. 训练数据的真实定义域没有提供给假设模型

训练集 2,361 行的合法零值：

| 输入 | 零值行数 | 比例 |
|---|---:|---:|
| PBF | 587 | 24.86% |
| PMI1 | 113 | 4.79% |
| PMI2、PMI3、SPAN、GeDi（各） | 54 | 2.29% |
| ASA、AV（各） | 28 | 1.19% |
| lsd_f、lsd_p | 0 | 0% |

真实提示只提供意义、单位和“正值训练中位数 reference 的定义”，没有 min/max、零比例、原子/线性分子例外、零 AV/ASA 的解释。正的 reference 不会令 `q_X = X / reference` 严格大于零。

复算所有数值不稳定拒绝的 30 个公式：RAG 15/15、Agent 7/7、KG 8/8 都在不稳定行上遇到了相关输入零值。不是预测器在评分后认为这些公式没用，而是此前就没有完整的数值定义域。

例如 RAG 第三次第二轮的 `rotational_inertia_poresize_scaling = log((q_PMI1*q_PMI2*q_PMI3)**(1/3))/q_lsd_f` 把 PMI product 宣称为严格正值，但 113 行相关零 PMI 使公式非有限。另一公式认为“positive reference”会保证 q 变量远离零，暴露了归一化和数据域的混淆。

RAG 第三次前两轮共六条公式全被拒绝，最后三条实际评分全负，最终零提升。RAG 第一次最终只保留 `log(q_LabuteASA)+log(q_density)`，评分 +1.84%、开发测试 -2.79%。这个名字和解释强调 planarity，但公式没有 PBF，引用来源没有给出该组合的确定系数或方程；它仍是模型自行组合的代理假设。

RAG 第二次可得到评分 +4.69%、开发测试 +3.15%，所以“RAG 完全失效”也不成立；其平均被候选浪费和第三次零收益拖低。

### 4. 检查门槛与公式生成没有形成修复闭环

`scientific_check` 要求声明域 99% 有限；因此 AV=0 的 28 行（1.19%）足以拒绝全域的 `log(q_AV)` 或除 AV。`checked_feature` 的后续 95% 有限和中位数填补尚未执行，不能用其容错来解释实际轨迹。

生成修复只有 JSON/机制 family 的结构化修复。公式数值不稳、物理映射不明确和导数方向错误，在逐候选检查后直接消耗本轮一个候选名额，下一轮才看到泛化 reason。3×3 实际变成“27 次输出、不同数量可执行假设”，并不等于每种方法都测试了 27 个有效候选。

这个门槛本身能挡住无定义的科学假设。改进应是提供训练域事实、执行预检并纠正可修复的表达，或有物理理由的分段模型；不应为了胜出放宽门槛或加任意 epsilon。

### 5. lsd_f/lsd_p 和空腔/窗口仍被模型混用

V3 的源字典保留原论文的最大自由球、自由路径最大球的定义。但 RAG 一些解释仍把 `lsd_f/lsd_p > 1` 称为“cage-window geometry”，也有 KG 候选叫 `cage_path_bottleneck_contrast`，令读者误以为变量是 cavity/window 直径。

当前字典必须显式说明二者是自由球/沿路径自由球量，不能把 ratio 的任一方向无条件解释为 cavity/window 或 kinetic trapping。边卡已经写有不等同 cavity diameter 的 caveat，但长文与反复的泛化转移要求并没有保证其实际执行。源原句支持“转动限域可能有贡献”，不会自动支持任意输入组合。

## 可以提出但尚不能确认的因果解释

1. **RAG 的文献诱导偏向 log 形式**：21/27 含 log，对应转动/平动统计力学原句；已确认这种行为差异和数值浪费。仍须同模型、同知识的短卡对照，才能证明文献长度或某篇文献造成它。
2. **知识增量不足**：当前 KG 原句和 RAG 已有原句重合，全部都是固定 D0 上的重表达，Agent 也能提出类似尺寸/孔径比。无法从保存结果确定 GLM 事先是否记忆了这些论文或有多强先验。
3. **长提示＋low reasoning 可能压低推理质量**：KG 平均输入 23k、推理中位数仅 16，但 provider 的 reasoning token 统计不是能力测量。没有模型/effort 因子实验，不能归因“模型太新太强”。
4. **现有图结构可能只稍微改善组织**：六张卡并无真正多跳拓扑，且对照只是另一种无损序列化；应限制结论范围。

## 合理的改进与隔离实验

1. 三模式共同提供仅来自训练输入的 min/max、zero rate、必要分子类别和变量语义消歧。固定目标仍是原论文 14D0，避免把修复只给 KG。
2. 本轮 ANN 拟合前执行同额度的 AST、单位、域、导数预检。允许数值表达修复一次，但不得在看到评分后替换低分候选，记录初始/修复后有效率和总调用量。
3. 转动物理明确区分单原子、线性、非线性分子；不要直接令零 PMI 进入非线性刚体转子 product，也不要用 epsilon 假装是同一个机制。若现有 DSL 无法表达正确条件，完善适用域/分段表示再统一测试。
4. 精简重复文献为去重机制段，保留全部关键适用条件、来源及可展开原文。短 RAG 基线与图模式接收相同事实、相同条件、相同人工变量映射，才能分离结构作用。
5. 第一阶段固定同一个 GLM，用当前配置与官方推荐高推理配置做配对试验；再用较弱模型做 3 模式的因子对照。较弱模型可能更依赖外部证据，也可能更差地处理条件，现有结果不能预测必然反转。
6. 扩证据应对未解释误差或变量映射开展检索，不是再添加同篇相似片段。加入 target-regime 适用性、争议和反例，以及“机制→物理量→可测代理→公式条件”的类型规则，让图能阻止或修复错误映射。
7. 保持每轮每模式三个有效科学候选的统一口径，同时报告总生成数、修复成本及有效率。若要主张3×3固定总生成预算，则不能隐藏失败，需将有效率作为结果。

这是一份诊断，不承诺某模式必然最佳，也没有据此重新选科学结果。新模型配置、压缩上下文、闭环修复、更多知识四个因子的效应须拆开验证。
