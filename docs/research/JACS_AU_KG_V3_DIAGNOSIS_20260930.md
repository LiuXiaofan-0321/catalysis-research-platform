# JACS Au KG-v3：为什么知识组没有超过 Agent

日期：2026-09-30。回溯对象是 9 条主试跑、3 条相同事实平铺对照、108 个提案、实际 API 使用量、证据池、生成/检查/评分代码和作者公开原始输入。没有新增 GLM 调用、预测器训练或服务器作业；没有修改已完成结果。

## 结论

**RAG 的首要问题已经定位到“公式生成没有理解原始输入的合法零值，检查拒绝后没有及时修复”；KG 的主要不足是知识组织改善尚未成为增量科学推理。模型太新/太强目前只是待检验的解释。**

应继续原论文 14 项 D0、每轮 3 个开放生成的公式、连续 3 轮。下一版优先把训练输入定义域、科学变量映射、预检修复和真实反馈闭环做好，再做同模型推理档位对照，最后比较中等能力模型。目标是让知识组产生可重复的净收益；目前不能承诺 KG > RAG > Agent。

## 1. 先分清“输出了公式”和“实际测试了公式”

以下均是三个生成重复的合计，数据划分和 ANN 拟合 seed 固定。评分是逐轮保留的主依据；已查看测试集只作开发诊断。

| 指标 | Agent | RAG | KG+RAG |
| --- | ---: | ---: | ---: |
| 平均评分 MAE 改善 | +6.61% | +2.18% | +5.55% |
| 平均开发测试 MAE 改善 | +2.78% | +0.12% | +2.30% |
| 生成提案 | 27 | 27 | 27 |
| 实际拟合并评分 | 16 | 11 | 17 |
| 数值域不稳定拒绝 | 7 | 15 | 8 |
| 拟合后有正边际收益的提案 | 6 | 4 | 8 |
| 最终保留公式 | 6 | 3 | 6 |
| 含 log/log10 的提案 | 7 | 21 | 11 |
| 声明覆盖全训练域的提案 | 4 | 20 | 9 |

RAG 只有 40.7% 提案进入 ANN，Agent 为 59.3%，KG 为 63.0%。RAG 第三条轨迹前两轮 6 个公式全部拒绝，第三轮 3 个公式可以运行但都没有评分改善，最终保持 D0。

有效候选中出现正边际收益的比例为 Agent 37.5%、RAG 36.4%、KG 47.1%。所以不能把当前结果解释为“检索出的公式普遍无用”。KG 有效候选中正收益比例最高，但正收益幅度不如 Agent：正候选的平均边际增益相对 D0 为 Agent 3.31、RAG 2.34、KG 2.46 个百分点。这是描述统计，候选受历史组合影响、并不独立。

## 2. RAG 被拒绝的具体原因：合法零值进入对数或分母

对 108 个候选重放原检查，全部复现保存结果，训练参考值与所有轨迹一致。2,361 条训练数据包含：

| 原生输入 | 零值行数 | 比例 | 解释 |
| --- | ---: | ---: | --- |
| PBF | 587 | 24.86% | 平面或退化几何表示 |
| PMI1 | 113 | 4.79% | 甲烷和乙烯；另有接近零的线性分子 |
| PMI2、PMI3、SPAN、GeDi（各） | 54 | 2.29% | 全部为甲烷的原论文表示 |
| ASA、AV（各） | 28 | 1.19% | 固定探针可达量为零的六种框架 |

原论文方法明确采用隐式氢表示，并在计算几何描述符前去除氢；甲烷被表示成单个球。因此这些零值具有实际建模含义，不能当作普通缺失值。[原论文方法 3.2 与表 1](https://pubs.acs.org/doi/abs/10.1021/jacsau.4c00429)

RAG 的 15 个不稳定提案可分为：

- 6 个遇到 AV=0。
- 1 个遇到 ASA=0。
- 5 个遇到甲烷 PMI3、SPAN 或 GeDi=0。
- 3 个遇到 PMI1=0 的线性/球形边界。

例如 `log(q_MW)-log(q_AV)` 在 28 个训练行上遇到 AV=0；`log(q_lsd_p/q_GeDi)` 在甲烷行除以零；`log(q_PMI1*q_PMI2*q_PMI3)` 不适用于零惯量的球形/线性表示。全部在有限差分扰动之前就已非有限；本批没有仅由扰动新造成的数值不稳定。

### 为什么模型反复生成这些公式

真实提示提供了变量意义、单位和正的参考中位数，却没有提供训练 min/max、零比例、线性/球形边界及探针含义。正的参考值不会让 `q_X=X/X_ref` 自动严格大于零。RAG 第三条轨迹的解释甚至声称 PMI 乘积严格为正，与实际数据冲突。

RAG 21/27 提案带对数，20/27 声明全训练域；Agent 分别为 7/27、4/27。文献中的统计力学表达可能诱导模型采用对数形式，却没有同时正确迁移适用条件。行为差异已确认，诱导的因果贡献需要上下文消融。

### 两套数值门槛没有形成一致协议

前置 `scientific_check` 要求声明范围内至少 99% 行有限；后续 `checked_feature` 允许全训练集至多 5% 非有限并用训练中位数填补。两者范围和门槛不同。AV 的 1.19% 零行足以触发前者，因此后者根本不会执行。

跳过前置科学检查，15 个 RAG 提案都能通过原后置特征检查；仅把前置 99% 改成 95%，14 个可通过，另一个声明范围内仍有 6.005% 非有限。这些是离线检查结果，**没有说明其 ANN 得分会改善，也没有证明这种填补科学合理。** 应统一物理域和边界规则，修复表达或建立合理条件分支，而不是直接降低门槛或给零惯量加任意 epsilon。

目前数值拒绝直接消耗本轮候选槽位，下一轮才收到笼统错误。结构化 JSON 可以修复，数值/变量映射错误却没有同轮修复机会，造成有限 3×3 预算被反复浪费。

## 3. KG 没超过 Agent：有用的组织，有限的增量

V3 已经保住完整 RAG 证据、去重并排除原 benchmark 结果污染；不能继续用 V2 的“KG 挤掉 RAG”解释本次结果。

但现有知识仍有明显限制：

1. RAG 只有 4 篇来源，23 个片段中的 19 个来自同一篇 `PMC6161062`。段落数量不等于独立机制覆盖。
2. 六张 KG 卡的原句全部已包含在 RAG 文本中；增加的主要是组织、条件提示和人工代理映射。
3. 六张卡分别是独立的两节点、一条边，没有共享物理量节点或跨机制推理链。
4. 每个非 Agent 模式的九轮都收到完全相同的证据成员集合。反馈查询改变顺序，没有补到新论文或新的反例。
5. 所有公式仍仅由原生 D0 构造。没有新增样本层面的观测信息，收益来自表示、科学归纳偏置与有限模型拟合。

Agent 同样获得变量释义、单位、训练参考和反馈，也能使用预训练科学知识，提出孔径/尺寸、面积/体积、惯量比等组合。现有六张卡尚不足以体现一个强模型难以独立完成的知识贡献。不能从这些结果确定它是否记忆过相关论文。

图组织版评分 +5.55%，相同事实平铺版 +5.37%，只差 0.18 个百分点。三对轨迹中差值方向也不一致；两种格式事实相同已核验，但没有固定同一个模型采样种子，不应把它当成精确配对的因果估计。当前结果不足以证明稳定的图结构优势。

KG 也有积极信号：有效提案最多、正边际候选比例最高、三条轨迹均有正评分/测试诊断提升，评分波动较小；全原始输入 HGB 的冻结公式迁移平均 +2.20%，高于 Agent +1.20%、RAG +1.43%。但这不是所有预测器和基线都最优。

## 4. 科学变量映射仍有错误，预测收益没有把它纠正

原字典沿用论文的名称，但没有充分消歧 Zeo++ 的三种球径：最大可容纳球 Di、最大自由通过球 Df、沿自由路径的最大可容纳球 Dif。`lsd_f` 对应 free sphere，`lsd_p` 是沿该路径的球径；不能交换成“f=腔、p=窗”。[Zeo++ 定义](https://www.zeoplusplus.org/about.html)，[计算输出说明](https://www.zeoplusplus.org/examples.html)

KG 第三条轨迹保留的 `log(q_lsd_f/q_lsd_p)` 却把 f 解释成 cage interior、p 解释成可通过窗口。KG 第二条 `q_lsd_p-q_lsd_f` 把独立中位数归一化说成相同尺度，并将大差值直接解释为网络连通性。现有数值检查能检查函数变化方向，不能确认这种物理解释。

Agent 的两个保留公式与自己声明的训练目标关联方向矛盾；KG 的六个保留公式中三个关联一致、两个矛盾、一个不确定。观察相关性不宜直接当作因果硬门槛，但应触发竞争机制和变量解释复核。当前预测 MAE 改善不等于机制已证实，Agent 排名第一也不表示其科学解释更可信。

## 5. GLM 太新/太强是不是原因

### 已核验的设置

三组实际返回的模型名都是 `glm-5.3-flash`。代码调用硬编码 `reasoning_effort=low`、`temperature=0.2`；当前配置文件中改模型/推理档/温度不会自动改变这些调用。所有输出都正常 `stop`，没有输出长度截断。

| 每次实际 API 调用均值 | Agent | RAG | KG+RAG |
| --- | ---: | ---: | ---: |
| 输入 token | 3,964 | 18,031 | 23,091 |
| 推理 token | 344 | 326 | 182 |

Agent 含一次结构化修复，共 10 次调用；RAG/KG 各 9 次。KG 推理 token 中位数仅 16。token 是供应方用量统计，不是推理正确性的直接测量。

官方支持 low/high/max，默认 max；官方文档推荐 `temperature=1`、`top_p=0.95`、`reasoning_effort=max`。[模型文档](https://docs.z.ai/guides/vlm/glm-5.3-flash)，[作者模型卡](https://huggingface.co/zai-org/GLM-5.3-Flash)

这给出一个可测试解释：较长的知识提示在 low 推理档下没有被充分核对。但官方通用推荐不等于本任务最优设置，也没有证据证明 low 就是排名原因。当前输入远未达到模型声明的上下文上限；简单继续增大输入/输出 token 上限不能解决已确认的域和映射错误。

### 对换弱模型的判断

较强模型可能已经掌握通用科学组合，外部知识的边际帮助较小；较弱模型也可能更依赖检索。这是合理假设。同时，弱模型可能更难处理长上下文、退化边界和条件迁移，结果会更差。只用一种模型无法区分这两种情况。

因此不建议把换弱模型作为首要修复。先继续 GLM-5.3-Flash，做好闭环，再比较 low/high（必要时 max）；随后预先选一个可用的中等推理模型跑相同三模式。比较知识组相对各自 Agent 的增益，同时报告绝对 MAE、有效率和成本。不能把“更弱 Agent 输得更多”当作当前强模型的问题已解决。

## 6. 下一版具体怎么做

### 第一步：共同修复生成与检查接口，保持 D0 和 3×3

- 给三组相同的训练输入摘要：min/max、分位数、零/近零比例、原论文伪原子定义、探针量限制及 Df/Dif 消歧，不给评分/测试行标签。
- 给每个失败具体诊断：哪个操作、哪个输入、声明范围内失败比例、属于未定义表达还是机制不适用。
- 拟合前允许同槽的表达修复，三组规则和上限相同；保留初稿、修复过程及成本。看到评分之后不能把低分候选当技术错误重写。
- 对球形、线性、非线性表示建立有依据的适用分支；需要 DSL 扩展时统一三组。保持原生数据零值，不伪造全分子几何。
- 科学检查与特征计算统一域/边界协议；明确数值稳定、公式方向一致、观察关联和机制有效分别意味着什么。

### 第二步：让知识用于复核和修正提案

可采用“先独立生成三个初稿，再按相同复核预算定稿”的流程：Agent 自我复核，RAG 查来源条件，KG 用相同事实加可执行关系约束检查变量映射和适用域。最终仍是每轮三个开放公式，不回到预设菜单。

这样让 RAG/KG有机会修正独立推理的盲点，而不是让整段文献占据提案过程。Agent 也获得同等额外调用或复核预算。若另行保留完整 Agent 候选并与知识候选取并集，评分不退步可能来自更大的候选集合；必须按增加的生成/拟合成本做单独扩展实验，不能声称是免费图优势。

### 第三步：建立任务机制图，而不是增加卡片数量

图的关键连接应是“机制→必要物理量→可用代理→适用条件→有效表达→反例”，用共享实体和有来源的类型规则实现。例如：识别球形/线性表示后，阻止套用非线性转子表达；区分探针可达体积与分子自由体积；区分平衡构型空间和动力学逃逸；明确 cage/path 直径的变量对应。

对反馈中的未解决问题查完整索引，新增来源仍经过 benchmark 排除、适用性和出处审查。去重重复原文，保留关键条件并可展开查看；按问题选证据，不把所有来源塞入每一轮，也不机械压低 token 上限。

图组织与平铺控制需要包含相同事实、条件、代理映射和人工审查结果，再比较实际图检索/规则操作，才能分清更好知识与图结构的作用。

## 7. 最小验证顺序与成功判据

| 顺序 | 对照 | 要回答的问题 |
| --- | --- | --- |
| 1 | 三组共同域摘要＋统一预检修复，对照当前原稿有效率 | 是否减少同类边界错误和候选浪费？ |
| 2 | 固定同一 GLM、同一提示、low vs high；按调用及实际成本记录 | 增加推理是否改善映射与有效公式，而非仅增加输出？ |
| 3 | 修复后三组；相同初稿/事实的文本复核 vs 图约束复核 | KG 是否真正纠正文本组漏掉的错误，带来更高收益？ |
| 4 | 预先指定中等模型与当前模型都跑三组 | 知识增益是否随基础能力改变？ |
| 5 | 冻结协议，扩拟合 seed、数据划分/框架或分子留出 | 排名和机制是否能够泛化？ |

先做可执行性及来源映射复核，再投入完整训练。阶段性可以增加预先指定的生成重复，但不能把同划分重复等同于独立泛化。每次记录全部结果和失败，不按出现预期排名才停止。

评分提升、科学一致性、跨预测器收益与外部泛化应分别报告。NMI 主线需要知识如何改进可检验假设的证据，最后的机制结论还要相应模拟或实验检验。
