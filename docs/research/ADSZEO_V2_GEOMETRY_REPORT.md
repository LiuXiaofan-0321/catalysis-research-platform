## 1. v1 平结果的根因诊断（oracle 分析，无 LLM）

用穷举特征选择回答三个问题（Slurm 3692794）：

1. **噪声底**：GCMC 目标的中位相对不确定度 0.50%（p90 1.84%），
   远小于 D0 残差——benchmark 不受模拟噪声限制，有真实 headroom；
2. **v1 catalog 的 oracle 上限**：`t_count`（T 原子总数）单特征加入 D0 即
   **+10.71%**（拓扑 macro-MAE 0.23511→0.20992），但三个模式的 LLM 全部漏选；
   全 25 特征 oracle 仅 +2.76%（特征间互相干扰）；
3. **信息位置**：去掉 HVF 反而略好（-0.30%）——HGB 下 HVF 与 density/void-ratio
   特征冗余；v1 候选与 D0 同源共线是平结果主因，LLM 选择失败是次因。

结论：v1 的"考题"里没有足够的新信息，且唯一的金子（t_count，一个无物理含义的
拓扑指纹）被所有模式错过。

## 2. 协议修改（v2）

1. **几何扩展 catalog（25→42）**：从 `framework_atoms` 坐标预计算泄漏安全的
   孔隙几何描述符并冻结为 `geometry-features-v1.csv`
   （sha256 `d61331247ba76468f36cb57eca8552f62acf8206e901998be8b66961497ac612`）：
   - 最小环分布（ring4/5/6/7/8/10/12/13+ 分数、ring_mean、ring_entropy）；
   - 配位序列 cs2/cs3 均值（IZA 标准拓扑描述符）；
   - T-T 键长均值/标准差、O-T-O 角均值/标准差；
   - Al 二级壳层分数（Al-O-Si-O-Al 关联）。
   计算经金刚石晶格单元测试验证；全部为预吸附框架坐标的确定性函数，
   `positions`/`cycle_stats` 仍被禁止。
2. **3 轮 validation-only 迭代**：每轮后向模型反馈所选集合及每个描述符的
   验证集拓扑 macro-MAE 增量，允许保留/替换；测试集只在最终轮评估一次。
3. 任务、query、模型、预算、split 与 v1 完全一致——唯一变量是 catalog 与迭代。

v2 oracle（Slurm 3692841）：`cs3_mean` 单特征 **+17.24%**，`ring_mean` **+15.48%**，
最佳三组合（cs3_mean+ring_mean+cs2_mean）**+23.69%**（0.23511→0.17940）。

## 3. v2 三模式 × 10 重复结果（Slurm 3692865）

| 模式 | 有效 | 平均改善 | 正向数 | 范围 | 平均 tokens |
| --- | --- | ---: | --- | --- | ---: |
| Agent | 10/10 | **+5.74%** | 7/10 | −2.07% ~ +14.54% | ~11k |
| RAG+Agent | 8/10 | +2.44% | 3/8 | −4.71% ~ +17.70% | ~148k |
| Small KG+RAG+Agent | 8/10 | +2.44% | 3/8 | −5.23% ~ +17.02% | ~127k |

对照 v1：Agent +1.02%（4/5）、RAG −2.51%、KG −1.45%——三种模式全部改善，
最好单次从 +3.6% 提升到 +17.7%。

## 4. 关键观察

1. **反馈闭环有效**：全部 top 表现的 run 都在最终选择中包含几何特征。
   RAG rep6 是教科书案例——第 1 轮全选 Al/孔隙率特征（验证增量 −1.5%），
   反馈后第 3 轮切到 `ring_entropy + cs3_mean`（验证增量转正 +0.4%），
   测试集 **+17.70%**；
2. **垫底的 run 全部卡在 Al 位点特征**（al_per_void_volume、al_close_pair_*、
   al_second_shell）——这些特征与 D0 冗余，是"吸附文献惯用语"的陷阱：
   模型倾向选择名义上吸附相关的特征，而非数据中真正正交的拓扑特征；
3. **模式差异仍不能下结论**：Agent 均值最高（10/10 有效、token 只有 1/13），
   但知识模式达到更高的单次上限（+17.7% vs +14.5%）且方差更大。
   有效样本 8-10 个不足以分辨 +2.4% 与 +5.7% 的均值差；
4. **验证集是下一个瓶颈**：19 个验证拓扑的 macro-MAE 反馈噪声大
   （agent rep9 的验证增量逐轮变差但测试 +14.5%）。扩大验证拓扑比例或
   k-fold 反馈可稳定选择。

## 5. 宽松校验重跑（Slurm 3693097）

针对严格版 4 次 schema 失败（均为输出格式违规：描述符数量不符、非法
epistemic_status），把校验放宽为"确定性修复 + 记录在案 +（必要时）一次
schema 修复重试"：超预算截断、非法/ D0 描述符丢弃、缺失字段填
"unspecified"、非法 epistemic_status 矫正为 tentative、agent 引用证据剥离
并记录。内容性重试仍然禁止。

结果（同 prompt、同模型、同预算，仅校验策略变化）：

| 模式 | 有效 | 平均改善 | 正向 | 范围 |
| --- | --- | ---: | --- | --- |
| Agent | 10/10 | +6.84% | 7/10 | −2.80% ~ +20.45% |
| RAG+Agent | 10/10 | +1.52% | 4/10 | −5.03% ~ +11.85% |
| Small KG+RAG+Agent | 10/10 | +4.09% | 5/10 | −4.71% ~ +15.32% |

90 次生成中仅 3 次确定性修复、0 次模型级重试、1 个欠额轮次——格式违规
不再是有效样本量的瓶颈。两次运行并非配对样本（生成有随机性），均值波动
在 n=10 噪声内；结构性格局不变：Agent 均值领先，知识模式方差更大，
模式间差异仍需 20+ 重复与配对检验才能分辨。

## 6. Catalog 盲化实验（v3，Slurm 3693194）

v2 的一个混杂因素：42 个候选的 `scientific_rationale` 文本对所有模式可见，
Agent 不需要外部证据即可读到"最小环尺寸分布的香农熵"这类蒸馏知识。v3 把
rationale 从 prompt 中完全移除（所有模式只看到 descriptor_id + formula +
units），rationale 全文保留在 run artifact 的 `catalog_blinding` 字段供审计；
检索证据成为解释"描述符为何重要"的唯一通道。校验策略、任务、模型、预算、
split 与 v2 宽松版完全一致。

| 模式 | v2 宽松版（rationale 可见） | v3 盲化 | 几何特征入选率 |
| --- | --- | --- | --- |
| Agent | +6.84%，7/10 正向 | +7.63%，**10/10 正向**（+3.36%~+13.49%） | 10/10 |
| RAG+Agent | +1.52%，4/10 正向 | +6.39%，7/10 正向（最高 +18.77%） | 9/10 |
| Small KG+RAG+Agent | +4.09%，5/10 正向 | **+8.63%，10/10 正向**（+0.22%~+18.13%） | 9/10 |

关键变化：

1. **Small KG+RAG 首次成为均值最好的模式**（+8.63%）且全部正向、下限最高
   （最差 +0.22%）——排序方向首次与预注册科学假设一致（KG ≥ Agent > RAG）；
2. **盲化消除了"陷阱特征"**：v2 中 LLM 被"吸附文献惯用语"式 rationale
   （如 Al 电荷密度类）吸引，v2 宽松版仅约 6-7 成 run 选到几何特征；
   盲化后 29/30 个 run 的最终选择包含几何/拓扑特征——说明被移除的
   解释性文本本身在误导选择，而证据与公式名才是可靠的选择依据；
3. RAG 均值从 +1.52% 升至 +6.39% 且上限最高（+18.77%），但仍低于 Agent
   均值——检索质量仍是知识模式的短板（单条固定 query、混入弱相关 SI 片段）。

诚实限制：n=10/模式，模式间均值差（+8.63% vs +7.63%）仍在噪声范围内，
需 20+ 重复与配对检验；v2/v3 为非配对比较（生成有随机性）。

## 7. 充分功效下的排序检验（n=40）与证据净化（2026-09-19）

v3 的 n=10 快照（KG 均值第一）在扩大功效后被**证伪**。

### 7.1 Run A：v3 协议补跑到 n=40（Slurm 3693359 + 3693194 合并）

| 模式 | n | 均值 | sd | bootstrap 95% CI | 正向 | 几何特征入选 |
| --- | --- | ---: | ---: | --- | --- | --- |
| Agent | 40 | +7.03% | 5.93 | [+5.26, +8.86] | 33/40 | 37/40 |
| RAG+Agent | 40 | +6.83% | 7.31 | [+4.63, +9.10] | 31/40 | 37/40 |
| Small KG+RAG+Agent | 40 | +5.16% | 8.49 | [+2.57, +7.78] | 28/40 | 37/40 |

Mann-Whitney U（双侧）：全部两两比较不显著——
KG vs Agent p=0.18（均差 −1.86%，CI [−5.02, +1.41]）、Agent vs RAG p=0.74、
KG vs RAG p=0.35。**在本 benchmark 上三种知识模式统计不可区分。**

### 7.2 Run B：分族净化检索 n=39×2（Slurm 3693360）

三个分族 query（拓扑/孔体积/组成）各自检索后轮询合并，保持与单 query
完全相同的 item/token/per-paper 预算。结果：RAG +6.46%（vs 单 query
+6.83%，p=0.79）、KG +5.93%（vs +5.16%，p=0.76）；**方差未下降**
（sd 7.67/8.50 vs 7.31/8.49）。证据查询组成不是方差来源。2 次失败均为
GLM 原始 API 返回坏 JSON（非 schema 违规）。

### 7.3 结论与解读

1. **排序被证伪**：n=10 时观察到的"KG ≥ Agent > RAG"是采样噪声。
   充分功效下三模式均值的真实差距小于 ~2%，方向不稳定；
2. **稳健的正面结果**：几何 catalog 本身有效——所有模式一致获得
   +5~7% 的均值改善、~82% 正向率、~93% 的几何特征入选率。这是
   "假设→描述符→ML 验证"闭环的价值，与知识模式无关；
3. **知识模式无增益的原因**：特征名与公式自解释（cs3_mean、ring_entropy
   等命名即语义），强 LLM 的预训练先验足以完成"从可见菜单选择"类任务；
   文献证据在此任务上是冗余信息；
4. **方差来源**：单次波动（sd ~7-8%）主要来自选择组合与 HGB 对不同
   特征组合的敏感度，而非证据质量（净化实验证明）。

### 7.4 对论文主线的含义

本 benchmark 作为"知识有效性"的检验平台已经到达天花板：任务形态
（可见菜单内选择）无法区分知识条件。后续分化要靠任务重设计：
(a) 开放式描述符提名（不给候选菜单，只给 D0 与 allowed inputs）；
(b) 模型规模消融（弱模型下知识补偿假设）；
(c) 跨领域知识条件（LLM 先验薄弱的领域）。本报告的 n=40 零结果是
诚实的、有功效保障的负结果，本身支撑"知识价值依赖任务形态"的论点。

### 7.5 模型规模消融：glm-4-flash（Slurm 3695325，n=20×3，thinking=disabled）

| 模式 | 有效 | 均值 | 几何入选 | 独立选择数 |
| --- | --- | ---: | --- | --- |
| Agent | **0/20** | —（全部 schema 崩溃） | — | — |
| RAG+Agent | 17/20 | **−0.33%** | 17/17 | **2** |
| Small KG+RAG+Agent | 19/20 | **−0.67%** | 17/19 | **5**（含 4 个单描述符欠额集） |

（glm-4-flash 不支持 thinking 参数，属"弱模型包"的一部分，与 glm-5.3 的
对比含此混杂。）

三个发现：

1. **能力下限**：弱模型无证据时 100% 无法产出合规 JSON（agent 全灭）；
   有证据时能完成但选择质量崩坏——最终改善为负（−0.3~−0.7%，与
   glm-5.3 的 +5~7% 差异显著，p=0.008）；
2. **"知识补偿能力"假说被否定**：若文献证据能补偿模型能力，弱模型+
   证据应保持正向。实际它锁死在 2-5 个近乎确定性的选择上，且恰好落在
   al_* 陷阱特征组合（文献流行先验）——证据没有提供选择质量的信息，
   反而强化了错误先验；
3. **根本原因确认**：描述符的真实效用是数据集特定的（哪个特征在这个
   GCMC 数据上有增量），协议正确地对所有模式隐藏了它；文献语料原则上
   不包含"cs3_mean 优于 al_close_pair（在本数据上）"这类信息，而文献
   的流行度先验（组成故事）与数据集效用反相关。因此：
   强模型靠名字+先验 ≈ 弱模型拿证据也没用——**任务形态（可见菜单
   选择）没有给知识留出发挥空间，这才是与理想结果相悖的根源**，
   模型强弱只是放大器。
