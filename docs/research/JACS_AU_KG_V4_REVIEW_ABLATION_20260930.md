# JACS Au：固定候选复核消融与后续公平验证

日期：2026-09-30。状态：**输入和离线阶段回放代码已准备；真实 ANN 回放及新模型复核均未执行。** 本文是诊断阶段的预声明设计，不是已取得消融效果的报告。原 V4 协议、轨迹、汇总和恢复来源保留。

## 问题与估计对象

1. 在同一初稿、同一 D0+历史保留组合上，复核是否提高可执行率和最终评分收益，是否丢掉原本有价值的初稿？
2. 同事实图路径相对平铺事实是否有增量，而非多给条件、人工映射或训练相关性？
3. 相同候选的 low/high 复核是否产生更可靠的式子、声明及收益？

这与完整闭环 Agent/RAG/KG 排名不同。固定历史组合是受历史方法影响的条件上下文；这里不沿消融结果生成下一轮，不把局部差值累加成虚构的三轮终点。全部 54 批次、162 槽都进入，保留无效与失败，不根据诊断例子抽样。

## A：先做零 API 的历史阶段回放

[固定批次输入](../../research/reports/jacs_au_kg_v4_diagnosis_20260930/fixed-review-blocks.json) 用历史三轮的每轮作为一块。每块的 reference 都为原生 14 项 D0 加**该轮开始前历史实际保留的公式**，不包含该轮任一试验候选。

对 blind_drafts、reviewed_candidates、final_candidates 三个阶段分别执行原 V4 训练侧预检，再评分所有可执行候选。规则保持不变：ANN 4000 epochs、fit seed=3、原数据/划分/目标换算/标准化；不修复原稿，不给任意 epsilon，不换声明方向，不进行评分后的改式。拒绝槽保留拒绝，阶段没有合法改善则保持 prefix。

每个阶段记录 `best_including_prefix_mae_R`；相对 D0 的本轮增益为 `100*(prefix_MAE-best_stage_MAE)/D0_MAE`。主配对差值为 final_gain−blind_gain，次要差值为 review_gain−blind_gain。共同可执行槽的逐槽差值作为次要指标，不能用幸存槽取代全体批次结论。

脚本按 0..53 的固定块编号运行：[replay_jacs_au_kg_v4_candidates.py](../../research/scripts/replay_jacs_au_kg_v4_candidates.py)。逐块新建输出；每块保留阶段原式、检查、拒绝原因和拟合复用标记。完全相同字符串且已通过预检的表达在同一 reference 中复用一次拟合；不把符号反转、仿射等价或单调变换当成相同候选来删去。最多 486 个阶段槽，按合法性与精确重复减少实际拟合；另需回放非空历史 prefix。

服务器命令模板（路径无凭据；尚未提交）：

```bash

PYTHON="$BASE/envs/py312-rag/bin/python"

  --output "$REPLAY_RUN/blocks/block-$SLURM_ARRAY_TASK_ID.json"
```

54 块全部纳入。服务器运行前检查代码环境与原 ANN 一致；报告每块 prefix 和 final 与原记录的 MAE 差值，不静默替换原数值。先预声明回放匹配容差 1e-6 R；超限先作为环境/复现问题调查，不能依据是否改变排名决定容差。候选拟合失败标记 incomplete、记录全部事件，不能作为无收益零值混入完整均值。恢复只能对同一固定候选处理技术中断，不重新生成。

这一步能回答具体实例的反事实，例如 low-KG-1/R3 的差值是否优于被重复的乘积、high-RAG-1/R2 的惯量原式是否优于 exp 改式、high-KG-3/R1 删 MW 的净效应。结果不论方向都报告，也不据此挑选进入下一阶段的候选。

## B：固定初稿的四臂复核，交叉 low/high

四臂都从相同三个 blind_drafts 出发，看到相同 training_only_prechecks、公共变量定义/域和冻结历史反馈，最多一次训练前修复。仍只评分各臂三个最终槽；不能把旧稿与新稿取并集，不能扩大某组 ANN 搜索预算。未审查的新论文、benchmark 原文/SI/描述符答案继续排除。

| 复核臂 | 上下文 | 核心对照 |
| --- | --- | --- |
| self | 公共契约、初稿和共享训练预检 | 自我复核基线 |
| source | 同一来源原句、条件、机制卡 | source−self：当前知识上下文的增量 |
| flat_graph | source 的全部内容＋图的所有节点属性和关系，平铺为事实元组 | flat_graph−source：额外组织/映射事实的增量 |
| graph | 同样 source 内容＋相同节点属性和关系，节点/边结构表示 | **graph−flat_graph：同事实表示的主比较** |

source 包含 V4 原本 RAG 就会得到的机制卡；不能把它称为“只有未经加工原文”的 RAG。平铺组可见全部关系，因此比较的是图结构表达，不是“模型能不能知道某条关系”。当前实际执行预检在四臂完全相同，不能把 graph−flat_graph 的差异说成执行引擎优势。

为隔离复核，本阶段对所有 54 块用已审查 **V3-final 转换的 V4 固定库**一次确定性检索，固定 10 条上限、条件及六张机制卡；三个知识臂逐块证据完全相同。它不是历史 live-index 检索的精确重放，也不评估动态检索优势。Agent 来源初稿也有同样的预先准备证据，避免只消融知识组留下的候选。原始动态检索段落另保存在 candidate-audit.json，留作历史分析。

新输入修正条件指针为 `evidence.source_conditions.Cn`；图输出不再把检查名称列为已执行结果。图与平铺的全部事实可相互重建，新增回归检查已验证。用 `diagnose_jacs_au_kg_v4.review_request(block, arm)` 构造请求；固定输入不包含本块原最终公式或本块评分结果。历史前轮反馈确有前轮 MAE，四臂相同，必须报告这一条件，不能声称复核完全看不到任何过去评分。

每块×四臂×两档×三次复核重复，总计 **1,296 个复核批次、3,888 个最终评分槽**，不重新生成盲假设。每个档位原来的模型/温度/输出上限/截断恢复上限/等待配置不变；不要求用满 token。生成重复与来源盲生成 effort 分别记录，不按同编号当作共享供应商采样种子。使用固定任务表、预先随机且分层平衡的调度顺序（调度 seed=20260930），避免总先跑某一方法；三次全部完成后汇总，不看排名决定是否增加重复。

主结果：每块、每档先对三个复核重复求均值，再求 graph−flat_graph 的配对差值，报告六个来源分层（origin effort×origin mode）及全总体等权结果。其余预声明对比为 source−self、flat_graph−source、graph-high−graph-low 和 source-high−source-low。候选不独立，54 轮还嵌套于18条来源轨迹；不把 3,888 槽当独立样本。报告来源轨迹级 cluster bootstrap 区间（10,000 次、seed=20260930）与逐轨迹差值；六层各三条的小样本局限必须保留，区间仅作开发诊断。不能用事后最好的层或指标替代主比较。

有效率、passed→rejected、机制/代理漂移、目标文字与字段矛盾、定义误用、候选精确重复、实际 token/调用/失败数均为共同报告项。机械 support-change 只标旗；按预先审查表、隐藏方法标签进行语义审查，记录证据句、迁移假设、替代机制及评分不可见的判定理由。预测收益和科学一致性分别报告。

为隔离“训练关联匹配”与图事实，另预声明 source/graph 各一个 no-association 版本：只从当前和历史训练诊断中移除 training_spearman 与 target_association，保留域、量纲、定义、导数及历史评分反馈。全部 54 块×两臂×两档×三次，共另 **648 个复核批次**；与主阶段相同临时段落顺序和预算。draft 的自然语言可能已提及以前相关性，故此对照仅测量**额外显式关联反馈**的贡献，不能称为从初稿完全擦除标签信息。所有批次应在执行前写入同一任务表；不能看到 B 结果后挑案例或补次数。

本次只准备固定输入和历史离线回放脚本，**尚未实现或启动 B 的在线调度/汇总器**。执行 B 前要把上述臂、次数、对比、失败与恢复政策落实为机器可校验配置并通过预算/字段回归；不能将现有“prepared_not_run”改写为完成。

## C：根据诊断需要修复的协议缺口

以下为待实现的新版本方案，不追溯修改 V4，也不以维持某种排名为验收条件。

1. **区分表达技术修复和假设修订。** 新字段记录 edit_type、旧/新代理集合、方向约定、引用支持和修订理由。AV→Dif、比差→乘积、新增耦合项应显式标为 hypothesis_revision；不能由未改的 hypothesis 文本冒充“同一假设”。技术修复锁代理集合及定性关系，仍允许有依据的零边界/量纲修复。完整发现任务允许有限假设修订，但须更新版本和可证伪条件、计入原槽，三组同预算；固定“同假设”消融则拒绝这类替换。
2. **让符号约定与物理预言分开。** 同时记录描述符对每个关键物理量的方向、描述符→熵损失的符号约定、最终物理预测。对 `f→-f` 不能只因相关性一致就宣布机制得到支持；针对多个关键轴做公式/声明一致检查，相关性与执行状态分栏展示。
3. **防止复核损坏已通过候选。** 在新保全策略对照中，若审查把 passed 候选变为纯技术 rejected，同槽退回未改的初稿并记录退回；仍只评分三个候选，不同时评分旧新两稿。若初稿科学解释错误，保留科学标旗，不能因技术通过就宣布可信。这是应与 V4-style 自由改式作固定候选对照的策略，不预设它必定提高 MAE。
4. **避免在同一历史组合上重复已评分式、生成时处理历史冗余。** 先做字符串/AST 规范化重复检测；重复标识必须同时记录 reference 的历史公式组合。在组合已经改变时，旧负收益候选可能产生互补作用，允许依照预声明规则重新测试，不能一概禁止。对 q/reference 等价表达可再用训练值的仿射关系作标旗，不能把符号等价当新机制。评分反馈不得被训练相关性替代。已保留式的重交占槽明确记入浪费，不无限请求替代式。
5. **修复图可寻址性和审计真实性。** 条件引用可解析；检查日志区分 rule_names 与 executed_reports。若发展真正跨机制工具，应输出机制链、每步出处/代理假设、竞争机制以及推导如何改变候选，之后用同事实平铺工具对照，不能只增加图内容而把收益算作表示优势。

新协议上线前保留 V4-style 原策略对照，三组共享修复和检查。固定候选消融会暴露哪些修改有效，但不能据最佳候选/最好 reviewer 重复拼接一个“新方法”来报告收益。

## D：冻结后的扩大重复与泛化

后续完整发现建议预先固定每档每组20个新生成重复（120条轨迹、1,080槽），始终三轮三槽、每轮只保留一个改善当前组合的公式。全部结果与技术失败纳入；不能先看六组排序再决定多跑哪组。主 fit seed=3 沿用，另固定 seeds=7、11 对**同一套冻结公式**作优化稳定性诊断，不能选最好 seed。

新随机划分（预先固定三个种子 20261001/20261002/20261003）及框架/分子类别留出只能说明同一既有数据上的稳健性。该数据已参与开发，**重新划分不能变成独立验证**。独立评价应另留真正未参与开发的新样本/新体系或新的模拟/实验结果，在查看标签前冻结生成、检索、超参数、参考归一化和全部规则。评分仍用于选择，独立标签不能出现在域摘要、检索、复核或修复请求中。

继续同时报告 ANN 主评分、原外层开发诊断、冻结公式 HGB 迁移、科学解释一致性、成本与失败。树模型不给候选重选；无法支持统一收益就明确报告。最终投稿主张必须依据稳定的独立收益及可检验科学机制，不能靠 high 外层列的希望排序替代主评分。
