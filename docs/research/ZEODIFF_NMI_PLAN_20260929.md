# ZeoDiff：原生 D0、复现核对与 KG 改进方案

日期：2026-09-29。主线为 NMI 科学假设发现；保留“原论文 D0＋生成公式”的 3×3 闭环。

## 1. 论文和公开材料

论文为 Wang 等的 *Harnessing confinement effect and interpretable machine learning to predict alkane diffusion in zeolite catalysts*，
Nature Communications 17, 5414 (2026)，DOI [10.1038/s41467-026-71698-0](https://www.nature.com/articles/s41467-026-71698-0)。
研究甲烷在一维纯硅沸石中的扩散，主要数据条件为 298 K、无限稀释。
这些条件不能自动代表含酸位、含阳离子框架、多维孔道或任意温度/负载。

作者代码和数据：[ZeoDiff_HTP](https://github.com/WangXiaobao-j/ZeoDiff_HTP)、
[Zenodo v1.0](https://zenodo.org/records/18858951)。
本次按论文链接下载发布包、[补充材料](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41467-026-71698-0/MediaObjects/41467_2026_71698_MOESM1_ESM.pdf)
及[Source Data](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41467-026-71698-0/MediaObjects/41467_2026_71698_MOESM3_ESM.xlsx)。
原文件放在 `research/datasets/raw/zeodiff-2026/`，按仓库现有规则不提交原始大文件。

公开表 `Dataset/zeolite_diffusion_dataset.xlsx` 有 **4,194 行**。
全部九项输入均为有限数，扩散标签均为正。48 个样本 ID 为字母代码，4,146 个为数字代码；不能在未核对结构来源前把 ID 格式当成已验证的来源分组。

## 2. 有两套原生 D0，主实验采用完整九项

作者早期常规模型经过相关性过滤使用四项：**PLD、FDSi、Vacc、ASA**。
最终模型的完整 D0 是下表九项。表中的输入顺序与发布权重一致，依据作者 README、`config.py` 和 checkpoint。

| 输入 | 含义 | 原始数据单位 |
| --- | --- | --- |
| FDSi | 框架硅原子密度 | T / 1000 Å³ |
| PLD | 孔限制直径 | Å |
| PLD/LCD | 孔限制直径与最大腔径的比例 | 无量纲 |
| Vacc | 可进入孔体积分数 | %，不是 0–1 小数 |
| Tort | 路径弧长与直线距离之比，即曲折度 τ | 无量纲 |
| AvgA | 路径截面积均值 Amean | Å² |
| StdA | 路径截面积标准差 ASD | Å² |
| MaxA | 路径最大截面积 Amax | Å² |
| ASA | 按材料体积计算的可进入表面积 | m²/cm³，与 JACS Au 的面积单位不同 |

**主比较：D0₉＋X 对 D0₉。** Agent、RAG、KG+RAG 共用这套完整输入。
四项 D0 可作为另一个“重现作者如何加入物理描述符”的任务。τ、ASD、PLD/LCD 已由本文提出或使用，不能再作为我们独立的新发现。
即使生成表达式字符串不同，仍需检查它是否只是在改写已有关系。

## 3. 目标、公开模型和测试划分核对

### 3.1 目标变换

原始 `Ds` 存的是 `D / (10⁻⁸ m²/s)`，不是 SI 单位的 D，也不是已经取过对数的数。
发布 GUI 用 `exp(model_output) × 10⁻⁸` 恢复 m²/s，checkpoint 的输出对应自然对数。
Source Data 的散点坐标采用 `log10(Ds)`。

因此回放时将模型输出除以 `ln(10)` 后计算绘图口径的指标。
后续若训练自然对数目标，统一在 log10 口径报 MAE、RMSE、R²，并明确物理单位恢复公式。
不能把 RMSE 0.35 写成 0.35 m²/s。

### 3.2 发布权重回放

`ann_final_model.pth` 有完整模型状态、优化器状态、输入名和超参数。
结构为 **9→128→64→32→1**，隐层 ReLU。checkpoint 记录 dropout 0.2、batch size 16、weight decay 0.005、初始学习率 0.001、StepLR step size 100/gamma 0.3、无 batch normalization。
推理不启用 dropout。补充材料 Table S2 的结构和正则设置与此一致。

作者 `Supplementary data 11` 含 3,774 个互不重复且均存在于主表的训练样本 ID。
其特征均值、总体标准差与公开 scaler 吻合，误差在浮点精度范围。
利用这些 ID 重建训练成员，剩余 420 个作为作者模型的测试成员，结果如下：

| 发布权重回放 | n | log10 MAE | log10 RMSE | R² |
| --- | --- | --- | --- | --- |
| 训练成员 | 3774 | 0.228095 | 0.297058 | 0.936500 |
| 剩余测试成员 | 420 | 0.258607 | 0.346158 | 0.914164 |

测试结果与论文约 R² 0.91、RMSE 0.35 相符。只使用 SHAP 表的 ID，未使用 SHAP 值或原预测作为输入。
这是由成员 ID 与预处理统计核对的划分重建，未确认原始随机划分的生成步骤及行顺序。
SI 记载模型随机种子 3407；直接按该种子做 90/10 划分不能得到同一训练集合，不能擅自把它当作原划分种子。

### 3.3 尚未解决的版本与训练差异

- 主数据有 4,194 行。最终 ANN 绘图表实际有 3,827 个训练点、426 个测试点，共 4,253 点，且没有对应 ID。这些点对不都是重复行。
- 按最终绘图点对复算，测试 R² 0.903044、RMSE 0.348230；与 checkpoint 测试的差异要单独保留。
- 初始四项 ANN 绘图点对复算测试 R² 0.567798、RMSE 0.550541；不能直接把正文其他基线数字视为已复现。
- 发布包的脚本主要是 GUI 推理、特征提取及 MD 分析，未找到完整训练脚本。SI 提供部分设置，训练目标构造、损失、最大 epoch、早停及最终模型选择步骤仍需补齐。

这些差异尚不能确定来自版本更新还是导出/标注问题。先使用版本明确的主表建立配对实验，并在论文中注明从头复现与原作者回放的区别。

## 4. 为什么这个任务适合检验 KG，以及收益的限制

这个任务有明确原生 D0，也有可追踪的“结构 → 曲折/截面变化 → 输运”物理关系，适合检验关系组织是否改善假设。
但最终 D0 已包含较强的物理特征，ANN 和树模型表现均较好。
仅重新组合九个标量可能收益有限，不能预先保证 KG 最佳。

有价值的主张应是：KG 能更准确地连接条件、机制和可计算量，在同预算下提出更有效且可解释的公式，并在强预测器或新结构上保持收益。
目前 JACS Au 的 KG 上下文没有充分做到这些，优先修正可观察的实现问题。

## 5. KG 改进项

| 改进 | 具体做法 | 验证它是否有效 |
| --- | --- | --- |
| 所有组共用准确变量字典 | 固定九项的物理含义、单位、数值范围和条件；修正百分数、体积面积单位等歧义 | 检查变量误解与量纲拒绝率 |
| 构建扩散机制图 | 节点区分结构性质、能量/熵垒、输运机制、条件、观测与假设；边有方向、机制、适用范围、来源 | 审查关系是否受原文支持；记录证据来源与候选对应 |
| 给模型完整关系路径 | 输出例如“截面波动 → 条件化熵垒 → 扩散减慢”的路径语义、条件与原文依据 | 对照同一事实的文本表示、真实边和打乱边 |
| 每轮更新检索 | 根据当前公式、训练/评分反馈和竞争解释提出新查询，同时查支持与反例；RAG 同样允许更新查询 | 与固定上下文比较，检验反馈是否改善后续候选 |
| 共同的科学审查器 | 对三组统一检查量纲、数值域、已有描述符、假设与公式是否一致，保留驳回理由 | 计算有效假设率，审查器自身做抽样人工核对 |
| 必要时加入结构计算工具 | 先只用公开九项；后续可从 CIF/静态势能网格计算额外结构量，三组具有同样工具权限 | 报告计算成本；不能使用目标 MD 轨迹或标签派生量作输入 |

已有九项可支持的候选方向包括截面相对波动 `StdA/AvgA`、截面积比例 `MaxA/AvgA` 与曲折度的耦合。
这些是待审查方向，不能预先称为新规律，也不意味着只给 KG 组这些表达式。
`τ⁻²`、能垒激活形式等已有理论需要检索适用条件，不能只凭直觉拼成一个公式。
若静态势能网格得到能垒代理，应区分势能垒、自由能垒和输运测量，不混用名称。

## 6. 保持 3×3，加入能检验图优势的对照

每轮候选分别在 `D0₉＋已保留集合＋候选` 上拟合，与当前集合比较；最多保留一个评分改善者，无改善保持当前集合。
最终最多增加三个公式，允许最终只有 D0。评分改善非负由选择规则保证，独立测试改善不能保证。

### 6.1 基线与预测器

1. 作者 checkpoint 回放单独报告，作为来源核对。
2. 发现实验重新拟合配对 D0，候选用同样的训练数据、拟合种子和训练预算。不能一方用全部作者训练集、另一方因评分划分少用数据。
3. ANN 为论文对应预测器，RF/XGBoost/LightGBM 的公开设置作为强对照，HGB 可用作现有实现的辅助对照。
4. 在 ANN 上筛选后冻结公式，加入树模型评价迁移；另做以树模型反馈选择公式的同预算闭环。分别标明这两种任务。
5. 比较简单物理比值/交互项、随机合法公式或其他同候选预算搜索，判断增益是否只是额外特征和搜索次数带来的。

### 6.2 知识、预算与消融

- Agent、RAG、KG+RAG 共用变量字典、输入/工具权限、提示要求、LLM、3×3 提议数和拟合预算。
- RAG 与 KG 的来源语料相同，记录候选、来源数、实际上下文 token 和调用成本。限制长度后还要检查实际用量，避免重演 JACS Au 的长度差异。
- 主要知识条件允许各自检索；额外做“同一证据原文 / 同一证据带关系 / 打乱关系”对照，区分检索内容收益和关系结构收益。
- 本文及其 SI 用于 D0 与复现/新颖性登记。新发现实验的检索库排除 benchmark 原文和直接泄露其答案的片段；重现已知发现任务单独允许并标明。
- 统一审查器属于所有组的公共工具，其提升不能直接归功于 KG。

### 6.3 在合理任务中检验知识的价值

完整训练规模与完整九项 D0 保留为主要结果。可以预先增加低样本和新结构分布作为条件，检验知识是否提高数据效率/泛化。
低样本比例、结构分组方法和随机种子在看结果前确定，三组用同一设置。
结构家族需从结构信息定义，不能按测试误差选分组。
不同来源或未见框架的测试可探索，但字母 ID 仅 48 个，需核实来源并如实报告不确定性。
其他分子在论文中有迁移学习结果，但当前发布的主表只有甲烷；完整带 ID 的异分子标签未找到前，不承诺该对照可直接跑。

先用少量轨迹检查运行与证据质量，再增加多个数据划分、拟合种子和生成重复。
报告每个划分上的配对差及区间，区分 LLM 生成波动和数据泛化。
测试结果保留正负值；可以改进 KG 的机制推理，但不按测试排名反复改流程、抽取最有利的一次或预设三组排序。
