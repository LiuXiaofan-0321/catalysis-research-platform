# JACS Au KG-v4：完整轨迹回溯与固定候选复核消融

日期：2026-09-30。接续 NMI 主线；Jev、harness、ZeoDiff 暂缓。本次读取既有报告、代码、18 条完成轨迹及恢复来源，不新增 API 调用、不训练 ANN、不提交服务器任务、不覆盖原结果。

## 结论及证据边界

**low-KG 的前两条低收益首先表现为候选组合的增量不足；现有复核还存在重复已失败表达、按训练相关性改写表达和公式与锁定假设分离的问题。high-KG 更好的最终组合主要来自不同的盲生成轨迹，不能据此归因于图复核。**

high-KG 六个被保留公式中五个与盲初稿字符串完全相同；low-KG 为四个。知识直到复核阶段才进入，各档第一轮九次盲生成的请求内容完全相同。因此，第一轮不同方法的初稿差异来自未配对的随机生成，不能归为 KG 的首轮生成贡献。后两轮受此前方法各自的保留与反馈影响，不能当作同一输入的配对实验。

事实是最终公式和评分、复核修改及其理由、预检状态；**初稿和中间复核稿没有 ANN 评分**，当前记录无法确定“保留原稿会提高还是降低 MAE”。下面标出的机制漂移是逐案阅读结论；变量集合改变只作为审查线索，不自动构成违例。

完整评分均值仍为 low：RAG 6.87% > Agent 6.64% > KG 4.30%；high：KG 7.16% > Agent 6.98% > RAG 6.42%。high-KG 与 Agent 仅差约 0.175 pp；三次重复、固定划分和 fit seed=3 不支持稳定优势声明。外层数据已被开发过程查看，只作诊断，不替代评分排名。

## 1. low-KG 为什么前两条弱、第三条较好

以下边际增益均为 `100 × (本轮原组合 MAE − 候选组合 MAE) / D0_MAE`，单位为相对 D0 的百分点（pp）；只对被保留的边际值可以跨轮相加。

| 轨迹 | 第一轮保留及边际 | 第二轮 | 第三轮 | 累计 |
| --- | --- | --- | --- | ---: |
| low-KG-1 | `q_AV*q_LabuteASA/(q_GeDi+0.5)`，+2.896 pp | 无改善 | 无改善 | 2.896% |
| low-KG-2 | `log(q_LabuteASA/(1+q_AV))`，+1.420 pp | `log(1+q_Vol/q_lsd_p**2)`，+0.299 pp | `log(1+q_ASA*q_density)`，+0.961 pp | 2.681% |
| low-KG-3 | `log(1+q_Vol/(0.1+q_AV))`，+1.206 pp | `log(1+q_Vol/(0.1+q_lsd_p))`，+6.103 pp | 无改善 | 7.308% |

第三条优势主要集中于第二轮 h3 的一次大增益，**不是第三条全部轮次或全部候选都更好**。同轮 h1 和 h2 分别有 +2.217、+3.042 pp，但只保留最佳 h3，不能把三个正增益相加。

具体复核问题：

- **low-KG-1 / R3 / h1**：初稿 `q_lsd_p-q_lsd_f` 通过预检，训练相关性约 −0.015，标为 inconclusive。复核依据上一轮乘积式约 −0.79 的训练相关性，改成 `log(1+q_lsd_p*q_lsd_f*q_Vol**-0.5)`。该式与 R2/h1 的最终公式字符串完全相同；在相同未变的历史组合上再次得到 **−0.024 pp**。锁定 hypothesis 仍说“差值/对比”，rationale 已说“乘积容量”。事实：复核重复了已评分无改善的表达并改变公式语义；未知：被舍弃差值的 ANN 增益。
- **low-KG-2**：九个最终候选均可评分，三个保留量分别为 +1.420、+0.299、+0.961 pp；其余六个均为负。三个转动类槽均未保留。R3/h3 从 `log(1+q_ASA/q_density)` 改为 `log(1+q_ASA*q_density)`，最终 +0.961 pp；原稿未训练，不能把 +0.961 直接记为复核净收益。
- **low-KG-3 / R2 / h3**：初稿重复 R1 已保留的 Vol/AV 表达，预检因冗余拒绝；复核将 **AV 换成 Dif/lsd_p**，得到 +6.103 pp。引用 E02/E04（PMC6161062 的孔径/熵趋势）和 E08（10.1021/acs.jpcc.0c02671）。锁定 hypothesis 仍明确说固定探针比体积 AV，rationale/test 却改为路径包含直径。这是高收益的代理替换，不能记成同一假设的纯技术修复，也不能视为文献证明 Dif 等于分子可用空间。
- **low-KG-3 / R1 / h1**：原 `log(1+q_SPAN*q_MW/q_lsd_f)` 通过预检；复核不改公式却把对 `lsd_f` 的 descriptor_direction 从 decreasing 改为 increasing，导致拒绝。修复为 `log(1+q_SPAN*q_MW*q_lsd_f)` 才通过，最终 **−5.002 pp**。假设仍说小瓶颈增强限制，而公式改为随瓶颈增大。这里是复核制造错误、修复满足声明但改变机制的直接实例。

low-KG-1 三个转动槽、low-KG-2 三个转动槽和 low-KG-3 三个转动槽共九个均未保留。这个批次中转动候选占三分之一预算却未贡献最终改善；不能推出转动机制无效，只能说明这些具体表达在当前 ANN/组合上无正边际收益。

## 2. high-KG 的改善体现在哪里

| 轨迹 | 保留公式与边际 | 累计 |
| --- | --- | ---: |
| high-KG-1 | R1 `log(lsd_p/lsd_f)` +3.278；R2 `log(1+q_LabuteASA)-log(1+q_ASA)` +4.247 pp | 7.526% |
| high-KG-2 | R1 `log(q_lsd_p/q_lsd_f)` +3.278；R3 `log(1+q_PMI3)-log(1+q_PMI1)` +4.190 pp | 7.469% |
| high-KG-3 | R1 `log(q_Vol/q_lsd_f**2)` +3.351；R2 `exp(-q_AV)` +3.132 pp | 6.483% |

前两条以孔径比为第一步，再与表面积或惯量对比组合；第三条以体积/瓶颈对比搭配探针可达量的指数变换。high-KG-1 和 -3 第三轮各三个候选均负增益，按协议保持已有组合；不是每轮越加越好。

`log(lsd_p/lsd_f)` 与 `log(q_lsd_p/q_lsd_f)` 只差由训练参考决定的加性常数，标准化后表示等价。它也出现在 low-Agent-3/R1（同样 +3.278 pp）、high-Agent-2/R2、high-Agent-3/R3、high-RAG-2/R2。**不是 KG 独有机制**；不同后续组合的增益不能横向直接比较。

| KG，27 槽/档 | low | high |
| --- | ---: | ---: |
| 盲初稿通过预检 | 20 | 22 |
| 复核后通过 | 25 | 25 |
| 最终评分 | 27 | 27 |
| 训练前修复批次 | 2 | 2 |
| 复核改变公式字符串 | 10 | 5 |
| 通过预检初稿被改公式 | 5 | 2 |
| 正边际候选 | 9 | 12 |
| 被保留转动公式 | 0 | 1 |

high 不是靠更多补救批次取得改善。正边际候选更多、复核改式更少是观察事实；均不是推理档位或图结构的因果估计。两个档位生成序列不同，不能配对比较同编号重复。

两类 high 复核值得单独消融：

1. **high-KG-2 / R1 / h1**：`log(q_Vol)-2*log(q_lsd_f)` 已通过预检，但与锁定 entropy_direction=decreasing 的训练关联矛盾。复核仅变为负号相反的 `2*log(q_lsd_f)-log(q_Vol)`，相关性由 +0.670 变 −0.670，标签随之变 consistent；最终仅 +0.050 pp，未保留。关联“变一致”可由符号约定产生，并不增加信息或证明机制。相同 fit seed 下符号翻转也可能影响优化轨迹，不能声称 ANN 分数必然完全相同。
2. **high-KG-3 / R1 / h1**：初稿 `log(q_MW*q_Vol/q_lsd_f**2)` 通过预检。复核根据“质量双计尺寸、图中无 MW 支持”删 MW，并为匹配训练关联改为 `log(q_lsd_f**2/q_Vol)`，但没有同步改对 lsd_f 的 decreasing 声明，因此拒绝。训练前修复翻回 `log(q_Vol/q_lsd_f**2)`，最终 +3.351 pp 被保留；rationale 仍说“自由空间方向/已倒置”，最终关联仍 contradicted。这是有价值的最终表达与失效解释并存。图没有一条支持边，不等于质量项物理上错误；删 MW 的净收益必须实际配对评分。

high-KG 的已记录 reasoning token 较多（盲生成 35,991、复核 59,858、训练前修复 4,992；low 分别 1,093、5,505、1,197），但 token 不是推理正确性的测量。这些数值只覆盖完成/回放轨迹已有账目，不包含无法追回的旧失败响应。所有已记录尝试 finish_reason 均为 stop，没有已记录输出截断证据。

## 3. high-RAG 为什么均值仍低于 Agent

| 生成重复 | high-Agent | high-RAG |
| --- | ---: | ---: |
| 1 | 3.876% | 7.107% |
| 2 | 7.998% | 6.160% |
| 3 | 9.079% | 6.006% |

编号不是随机采样配对。RAG 实际比 Agent 更集中；均值落后约 0.56 pp 来自 Agent 两条较高轨迹，而不是 RAG 全面失败。RAG 有 27 个可评分候选、10 个正边际槽；Agent 有 26 个可评分、8 个正边际槽。正槽边际均值分别约 2.255、3.060 pp，这些候选依赖历史且并不独立，只作描述。

- **high-RAG-1**：R1 翻译类 `q_lsd_f**0.5*q_MW**-0.25*q_Vol**-0.125` +3.989 pp；R2 `q_AV**0.25*q_density**-0.125` +3.118 pp；R3 三个候选分别 −6.211、−6.630、−5.116 pp，最终停留 7.107%。第一轮胜者是盲初稿。
- **high-RAG-2**：R1 `log(q_Vol**(1/3)/q_lsd_f)` +1.262 pp；R2 `log(q_lsd_p/q_lsd_f)` +4.898 pp；R3 又提出两个已保留表达，分别因冗余进入修复，改成非对数比式后得 −2.939、−4.699 pp，第三槽 −2.271 pp。问题包括重复使用已经选入 D0+X+Y 的特征，没有获得新的有效互补表达。
- **high-RAG-3**：R1 `1/q_lsd_f**2` +3.880 pp；R2 孔径比平方加体积权重仅 +0.499 pp；R3 `sqrt(q_PMI3)` +1.627 pp。R2/h1 从 `(lsd_p/lsd_f)**2` 改成 `q_Vol*(lsd_p/lsd_f)**2`，理由包括原训练 Spearman 约 −0.019、关联不明确和 E06/E07 的分子尺度/笼空间论述。锁定纯路径对比假设未同步变成尺寸耦合。改后的 +0.499 pp 不代表原式一定更差。
- **high-RAG-1 / R2 / h1**：通过预检的惯量乘积幂式被改成 `rotor_case(1, exp(-sqrt(q_PMI1*q_PMI2)), exp(-(q_PMI1*q_PMI2*q_PMI3)**(1/3)))`。复核理由明确包括为了匹配冻结的目标关联方向而做单调递减变换，并引用 E03/E06/E09；最终 −0.698 pp。原稿没有 ANN 分数，不能据此声称 exp 变换损失了收益。初稿 rationale 把历史反馈说成与 `s_ads/s_gas` 的相关性，而预检实际针对 entropy loss/R，说明目标方向的文字理解仍会混淆。

high-RAG 七个胜者有六个保持初稿公式。因此，“high-RAG 低于 Agent 是复核普遍毁掉好公式”不获当前记录支持；“有几个值得检验的表达/代理替换”得到具体实例支持。

## 4. 复核的主要缺口：科学锁定不足、关联与收益混用

原程序锁定 slot_id、hypothesis、mechanism_family、entropy_direction，但普通复核可改 vary_input、descriptor_direction、regime、proxy_assumptions、physical_interpretation 和公式。训练前修复再锁这些字段，却仍允许改公式和变量映射。这样保证了文本字段不被重写，**没有保证同一可检验机制和代理语义被保留**。

全部 162 槽共有三次 passed→rejected：low-RAG-3/R1/h2（反转 AV 公式引入 AV=0 分母）、low-KG-3/R1/h1（改方向但不改式）、high-KG-3/R1/h1（翻公式但不改方向）。三次都最终修成可评分表达，所以最终 160/162 的健康有效率会掩盖中间审查制造的错误。

相关性报告来自**训练标签**，不是文献知识；三组均看到它。关联 contradicted 不会被硬拒绝，但模型常主动翻符号、加权或替换代理来匹配它。这个行为可能有助于表示，也可能使探索趋向高单变量相关性、损失非线性互补候选。后者是待检验假设，不能仅凭这些例子下结论。

“已通过预检”只说明可执行、维度和所声明局部导数等门槛通过，不说明自然语言假设自洽、引用充分、ANN 受益或物理因果有效。图/预检输出也没有完整验证所有自然语言声明，例如部分初稿把 SPAN 当作严格正量，实际训练有 54 个零值；high-KG-3 初稿把熵损失写成 `-ln(s_ads/s_gas)`，与本任务定义不符。

## 5. 图工具是否已帮助机制组合

事实核查：36 个知识复核轮均收到相同的前六个来源锚点及六张机制卡，覆盖四篇已审查论文；整轮 10 条记录集合共有 32 种，因此补充段落确实变化，不能沿用 V3 的“每轮完全同一证据集合”结论。RAG 也得到机制卡与迁移条件，KG 增加的主要是机制→共享代理→定义约束连接。

代码 `graph_paths_for` 依据候选变量过滤相邻边，没有实际搜索跨机制推导链；所有组三次阶段预检使用同一个 `precheck`。图返回的 `executed_checks` 是检查名称列表，并非此函数执行出来的逐候选结果；真正执行报告在 `training_only_prechecks` 中，三组共享。不能把有效率改善全记为 KG 独有工具贡献。

现有记录能支持：图上下文被用于代理选择理由（high-KG-3 删 MW）和定义/边界说明。不能支持：图已经构造独立于 Agent/RAG 的新机制链并因而提升 MAE。当前主要作用更接近**来源、代理和定义约束辅助复核**，是否具有增量机制组合价值仍待同初稿、同事实、同检查的图/平铺消融。

发现一个新消融必须修正的接口细节：图机制节点的 `conditions_ref` 写成 `evidence.mechanism_cards.<mechanism_id>.applicability_ref`，但 mechanism_cards 实际是数组。模型可人工寻找对应卡，程序不能按该地址直接解析。新消融输入已改为指向 `evidence.source_conditions.Cn`，且图/平铺两组保留完全相同的事实；原 V4 轨迹和代码未改写。检查名称改为公共预检政策说明，不再冒充图函数的执行结果。
