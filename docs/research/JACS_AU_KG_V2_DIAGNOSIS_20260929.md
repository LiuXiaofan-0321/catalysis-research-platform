# JACS Au KG-v2：根因审查与修正方案

日期：2026-09-29。审查对象为已完成的 9 条轨迹、81 个候选、逐轮实际提示证据、冻结证据池及检索/选择实现。本次没有调用 GLM、训练模型或提交服务器作业。

## 结论

当前实现存在可以复核的设计缺陷：**KG 替换了大部分 RAG 证据，重复图数据消耗上下文，路径主要组织文献而非表达可用机制，适用条件没有参与筛选，科学假设仅按 ANN 的 MAE 筛选。** 因此，“加入了 KG”尚不等于“为同一推理过程增加了适用的科学知识”。

另发现必须优先修正的评估污染：**原 benchmark 的 PMC 正文及补充材料进入证据池，正文 SHAP 结果进入 RAG 和 KG+RAG 的实际上下文。** 此前报告“已排除原论文”的表述不成立，本报告更正该结论。已保存分数仍是程序实际运行结果，但不能作为无 benchmark 结果污染的方法比较。

这些问题说明需要修正设计；尚不能确定每个问题分别造成多少 MAE 损失，也不能保证修正后 KG 排名第一。仅增加重复次数、提高 token 上限或换弱模型，都不能消除上述缺陷。

## 1. 先明确实际表现

提升为相对各自配对 D0 的 MAE 降幅，百分比越大越好。原生 14 项 D0、3×3、相同 ANN 与拟合 seed 保持一致。

| 模式 | ANN 自适应评分提升 | ANN 已查看测试提升 | 原生 D0 HGB＋冻结公式测试提升 |
| --- | ---: | ---: | ---: |
| Agent | 7.38% | 2.60% | −1.36% |
| RAG | 7.18% | 5.62% | +0.29% |
| KG+RAG | 5.53% | 3.00% | −3.14% |

KG 在评分和树模型迁移上最低，在 ANN 诊断测试上居中。三组各 3 条轨迹来自同一划分、同一拟合 seed，主要反映生成波动，不能作为稳定排名或跨数据泛化证据。以下审查不依赖将 KG 描述成所有指标都最差。

## 2. 新发现：benchmark 身份排除失效

外部身份核对：[PubMed 原始记录](https://pubmed.ncbi.nlm.nih.gov/39735916/) 将 DOI `10.1021/jacsau.4c00429`、PMCID `PMC11672123`、PMID `39735916` 列为同一论文。

本批 `bank.json` 中：

- `source_audit.excluded_paper_ids` 只含另一篇 Science 论文，没有该 JACS Au 论文的 PMC 身份。
- RAG 池中存在该身份的 11 条记录，来自两个文档，覆盖正文及补充材料。
- 实际上下文包含原论文 4.3 节 SHAP 分析、特征贡献和孔结构解释。不是只引入合法的 D0 方法定义。
- KG 池的 25 条行记录没有该论文身份；KG+RAG 的污染来自其 RAG 部分。该检查不等于已穷尽审查所有图嵌套字段与其他论文转引。

| 模式 | 含该论文的轮次 | 每轮该论文条目 | 27 个提案中显式引用该论文 | 6 个保留公式中显式引用该论文 |
| --- | ---: | ---: | ---: | ---: |
| RAG | 9/9 | 3–4 | 24 | 5 |
| KG+RAG | 9/9 | 1–3 | 25 | 6 |

例如 KG replicate 3 的 `R2E08` 和 `R3E08` 均为原论文 SHAP 段落，生成的解释明确引用了该证据。引用数量表示可追踪的归因，不证明模型完全依赖它，也不能据此计算污染带来的增益。

**错误链条：** `load_evidence_service()` 依赖论文元数据字符串/DOI 匹配得到排除名单；没有强制验证 benchmark 的 DOI—PMCID—PMID—正文—SI 身份闭包。下游预检沿用同一份不完整名单，因而“预检通过”不能发现漏排来源。现有归档尚不能确定服务器原始论文元数据的哪一个字段缺失或异常，因此不把具体元数据错误当作已查明事实。

这属于检索知识中的 benchmark 结果污染，未发现把逐行测试标签直接送给模型的证据。它仍破坏了“不借用原论文结果发现公式”的研究设定，也使 RAG 与 KG 的差异混入了不同的原论文结果暴露。

对上一批本地冻结证据文件的简单身份检索未发现 `pmc:pmc11672123`；不能把本次确认的污染自动扩大到全部历史实验，也不能凭该检索宣称历史实验已通过完整审查。

**处理：** 保留本批原始结果并标记污染；修正 canonical 身份排除，正文、SI、镜像和版本统一处理；独立扫描最终提示中的来源身份和 benchmark 特有结果段落。D0 定义来自原论文方法的合法白名单应与结果检索分开。未来重跑须生成新的目录，不覆盖本批。

## 3. 最直接的设计问题：没有保住 RAG 基础证据

`select_evidence()` 先放入 8 个 KG 条目，再交错加入 RAG/KG；两者共用每篇 4 条的配额和总 token 上限。KG 条目携带多个完整节点、边及支持引文。

实际纯 RAG 每轮 32 条；KG+RAG 每轮只有 4–7 条 RAG，其余为 16–17 条 KG。用 KG 每轮的**同一个查询**离线重放纯 RAG 选择后，32 条锚定原文中只有 4–7 条在 KG 的任一通道得到原样保留，平均 6 条，即平均 81.25% 的锚定原文缺失。

该计数按论文身份＋精确引文匹配；不声称语义相近的知识完全消失。但它明确说明当前比较同时改变了“图结构”和“正文证据集合”。因此无法把差异单独归因于图推理。

### 无需训练即可验证的修正空间

对九轮实际上下文，把完全相同的节点、边、支持引文对象只保存一次，路径改为引用对象 ID。保留每个字段、限定条件和出处，并断言反序列化后与原对象完全相等。

| 序列化方式 | 平均词法 token | 九轮范围 |
| --- | ---: | ---: |
| 原 KG 上下文 | 31,928 | 31,891–31,966 |
| 相同事实无损去重 | 19,782 | 19,233–20,609 |
| 同查询全部 32 条 RAG＋原来选中的 KG，统一去重 | 30,190 | 29,737–31,032 |

**相同事实去重约节省 38%；九轮的完整 RAG 锚点＋原 KG 均可放入当前 32,000 上限。** 这是确定的序列化改进空间，不是重新调用 LLM 后的性能结论。反事实合并仅用于测量，仍含已发现的污染，不能直接作为新实验证据池。

原 KG 每轮图边支持引文平均出现 182.1 次，独立字符串只有 61.1 段。当前先修重复表示和证据覆盖，比直接把上限继续加大更有依据。输出均正常结束，没有输出截断；也没有证据证明 GLM 的推理能力是主要瓶颈。

## 4. 图连接多，但与公式推导所需的关系不匹配

逐轮实际图边出现次数中，77.4% 为 `PAPER_*`，如论文报告实验、论文研究反应、论文包含关键词。它们有文献定位价值，但不能直接推出物理变量之间的约束。

真实路径示例：

- CO₂/LTA 实验 → 使用分子动力学 ← SF₆/NaY 转动扩散实验。
- NaF 对 SSZ-13 孔结构的实验 → 使用 SSZ-13 ← Cu 位点 NH₃ 脱附熵实验。
- 一篇环境应用综述 → 提到 MFI ← 另一篇拟合平移/转动熵损失的实验。

这些连接存在于原图，不等于提取造假；问题是共享“方法/材料/关键词”不能充分支持跨体系拼接机制。

检索器当前明确采用词面种子＋至多两跳遍历。邻接按双向可达探索，路径输出仍保留原始边方向；可达性本身没有适用性证明。`compact_paths()` 优先较长路径，而不是更能支持目标公式的路径。下游排序使用关键词相关性和词重叠，未使用保存的 `source_score`，也没有给条件匹配、关系价值或新信息单独评分。

**处理：** 保留文献图作来源索引，另建可审查的任务机制层：物理量、机制、适用条件、观察、方程和假设。允许有出处的关联、约束、近似及反例，不把共现自动改成因果。路径只有在能够解释“哪个机制在什么条件下约束哪个可用变量”时才进入提案上下文。抑制 adsorption、分子动力学等通用枢纽。

## 5. 适用性筛选太弱：同一个词跨越不同物理问题

当前 `relevance()` 主要检查 entropy/rotation/translation 与 adsorption/zeolite/confinement 的共现；`scope_tags()` 只标注少数正则命中，未参与排序或拒绝。`clean_excerpt()` 会保留含相关词的段落，其他段落中的条件可能被移出提示。

从实际 KG 池可以确认以下风险，判断针对归档引文与图节点，不声称相应论文的研究本身有误：

| 记录来源 | 池中内容 | 对当前目标的适用性问题 |
| --- | --- | --- |
| `10.1039/c003977b` | 沸石四面体的平移/转动自由度与框架柔性 | 框架自由度与吸附分子自由度混在同一检索规则中；当前 benchmark 使用刚性框架 |
| `10.1039/b800803e` | 限域双萘分子的磷光/转动受限 | 可作受限运动类比，不能直接证明一般吸附熵公式 |
| `10.1063/1.1647049` | SF₆/NaY 转动扩散率 | 动力学量与平衡熵不同，含阳离子体系还需迁移假设 |
| `10.1021/acs.jctc.7b00716` | Cu 位点 NH₃ 脱附的内熵 | 活性位相互作用与纯硅无限稀释几何限域不同 |
| `10.1039/d2cc02003c` | 正丁烷分子内二面角转动势垒 | 内扭转、整体转动、熵不是同一物理量 |
| `pmc:pmc5337972` | 水相环己醇脱水缔合复合物熵 | 水相反应/缔合与目标吸附平衡存在明确体系差异 |

有效相关证据也存在，例如孔径与吸附分子自由度损失的实验观察。问题是当前没有区分直接证据、可迁移近似、背景类比和不适用证据。图结构可能让弱类比呈现为可信度相同的证据链。

**处理：** 为每条候选机制记录物理对象、目标量、材料化学、温度、负载、框架刚性及关键假设。未知条件回查原文；不适用事实不参与本任务推导；类比明确标注且不获得直接证据权重。保留条件和反例，避免“只留下相关关键词”。

## 6. 提出的内容叫假设，实际反馈主要还是公式的 ANN 得分

当前模型会生成机制、适用范围和证伪标准，代码实际执行的是：量纲/语法检查 → 数值可计算性 → ANN 拟合 → 比较评分 MAE。`falsification_criteria` 作为文字保存，未执行对应分层检验、极限检验或竞争机制检验。

这仍然是开放公式生成，区别于早期预设菜单重排；但尚未形成完整的科学假设验证。即使模型提出“某尺寸区间出现转折”，最终判据仍只是全体评分样本的 MAE。KG 提供的适用边界和反例无法通过相应反馈得到强化。

还存在两个物理表达问题：

1. `q_A=A/A_ref` 让表达式无量纲，却不会自动使其成为真实物理方程。`q_GeDi/q_lsd_f=1` 对应 `GeDi/lsd_f=GeDi_ref/lsd_f_ref`，一般不对应真实尺寸相等。不能把归一化比值阈值直接解释为几何贴合阈值。
2. AV 是每单位框架质量的探针可达体积，Vol 是单分子体积。`q_AV/q_Vol` 可以是经验代理，但不能仅凭单位归一化就称为分子的实际平移自由体积。惯性矩比值也需核对分子类型、零惯性矩和轴含义。

三组全部只由 D0 构造公式 `X=φ(D0)`，没有增加样本层面的新观测信息。可能改善有限样本拟合、表示或归纳偏置，但原 ANN/HGB 已具有非线性能力，所以收益本来就不会必然存在。KG 六个保留式仍主要是面积/体积/长度/惯性矩的比值或对数；引用 KG 并未证明利用到了图结构独有的约束。

**处理：** 保持 3×3，每个提案附可执行的变量映射、物理假设、适用范围和一项区别于竞争机制的检验。先做低成本极限/尺度/对称性及数值检查；训练数据内检验指定范围的残差规律，再评价预测增益。对 ANN 与 HGB 的结论分别报告。修复 `**(1/3)` 这种常量表达式被 DSL 拒绝的问题，三组统一处理。

## 7. 反馈检索与预算的次要限制

冻结池只有 25 条 KG、15 篇论文；每轮改变查询仍只在这 25 条中重选。相邻轮证据集合 Jaccard 相似度 KG 平均 0.841，RAG 为 0.709。相似度高本身不是错误，但结合冻结池可知系统无法补充池外的新证据。

查询由已保留公式的变量含义、模型建议及通用拒绝提示拼接。拒绝反馈只追加一段通用量纲/几何词语，评分增益和具体机制失败原因没有被检索器直接建模。模型获得了历史评分，但检索策略未形成对应的问题分解。

**处理：** 针对竞争机制、缺失条件或失败原因回查完整索引；对三组适用的知识模式开放同样的检索机会。记录新增证据解决了什么不确定性。上下文去重后再按有用事实量调预算，记录实际 API token，而非仅靠词法计数。

## 8. 为什么“理论上 KG 必然有正向作用”不成立

理想情况下，若原候选策略仍可选择、可忽略新增信息、目标是真实期望效用且能找到最优策略，扩大信息或策略集合不会降低最优可达效用。这不等于一次有限预算的 LLM 实现必定提高。

当前会替换原证据、加入跨条件类比、改变上下文长度和注意力分配；拟合、候选搜索和评分也有误差。因此不能把理想最优值的性质套在当前程序输出上。

D0 回退只保证**同一个自适应评分集**上不接受更差的候选。它既不保证新样本误差不升高，也不保证 KG 候选优于 RAG 候选。重复看评分越多，评分收益越需要外部泛化核对。

用户的方向仍值得推进：让准确、适用、有增量的结构化知识帮助提出更好的可检验假设。需要检验的是这种知识的实际贡献，不能提前把固定排名设成实验成立的条件。

## 9. 建议实施顺序与最小因果实验

### P0：先恢复实验可信度和证据覆盖

1. 修正 benchmark 的多身份排除与独立最终提示审计；标记本批污染。
2. 节点、边、支持引文无损去重；固定同查询 RAG 锚定证据，KG 提供附加事实或约束，取消无条件优先 8 条的机制。
3. 审查 25 条 KG 及其嵌套路径的适用范围；剔除无效跨体系连接。完整保留来源和条件，不臆造机制边。
4. 修正物理比值与归一化比值的解释规则、常量指数语法；三个模式共享。

通过门槛：最终提示无已知 benchmark 结果；锚定 RAG 原文覆盖 100%；去重可无损还原；所有被使用的机制关系具有出处和适用性结论。技术门槛通过不等于性能门槛通过。

### P1：把图的贡献与“多给文字”分开

保持 GLM-5.3-Flash、原生 D0、3×3、拟合规则不变，先做以下对照。事实和条件在序列化前固定，不能分别按不同长度重新选一批证据。

| 条件 | 输入 | 目的 |
| --- | --- | --- |
| A | 干净的 RAG 锚点 | 基准 |
| B | A＋经过适用性审核的附加事实，平铺表达 | 检验新增知识收益 |
| C | A＋与 B 完全相同的事实，显式图关系/路径组织 | 检验关系组织和推理接口收益 |
| D，后续可选 | 与 C 相同事实，移除特定关系组织或适用条件 | 检验关系/条件的贡献，分别做消融 |

平铺文本也必须保留原关系的语义；否则 B/C 同时改变知识内容，不能声称只测试图结构。现有 `graph_view=text` 会改变长度和随后选中的条目，不能直接当作上述严格消融。

若 B>A、C≈B，说明补充知识有效，未证实图组织优势；若 C>B，才支持图接口有额外价值。若 C 仍差，应按证据误用、条件迁移、公式覆盖、拟合波动逐项分析，不通过删掉负轨迹改变结论。

先用小试跑验证接口与方向，再对通过开发门槛的方案扩大生成重复和划分；只把随机生成重复增加到几十次，不能替代跨框架/跨分子泛化。首轮消融仍属于开发，已经查看的测试不作为新的盲测。

### P2：NMI 主线需要实际验证科学主张

将机制的适用区间、预测方向和反例检验加入闭环；固定一个 ANN 主评价器，另设明确的 HGB 评价协议。如果要证明对树模型有效，应在训练侧按 HGB 评分选择公式，再到未参与选择的划分评估；同时保留“ANN 选出的公式直接迁移”作为另一个问题，二者不混淆。

最终在开发后冻结协议，评估未参与方案选择的泛化集合，报告全部组别、成本、失败率、均值与不确定性。当前不需要换弱 GLM 或同时引入复杂 multi-agent；先修正已经定位到的输入和验证缺陷。
