## 1. 目标与模型决定

目标是在原论文完整 14 项 D0 和同样的 3×3 规则下，提高 KG+RAG 提案的科学有效性与预测收益。
三组继续使用 **GLM-5.3-Flash，thinking enabled、reasoning effort low、temperature 0.2**，与原批次保持一致。

目前不足以判断 GLM-5.3-Flash 太强而掩盖 KG 作用。原批次仍有变量含义错误、量纲问题和不相关证据。
强模型可能已掌握常见物理关系，压缩检索的额外收益，也可能更善于使用结构化证据；这两种解释需要实验区分。
当前先修正 KG 接口和证据质量。模型能力的消融作为后续独立变量，不为获得预期排序刻意选择弱模型。

原批次独立测试均值为 Agent +3.25%、RAG +3.64%、KG+RAG +3.22%。改进依据是实现与证据审查发现，
不依据某条轨迹的测试表现挑选有利公式。原记录、负结果和完整 14 项 D0 保留。

## 2. 本地已实施的改进

### 2.1 图关系真正进入提案上下文

原接口返回路径 ID 和归一化概念，新接口可额外序列化：

- 每条**连通路径**的节点类型、名称和原提取数据。
- 边的原始关系类型、source/target 方向、来源论文及支持引文。
- 实验或条件节点中的温度、材料、反应/吸附条件等已有数据。
- 提取/审查状态，并明确图遍历不等于因果证明。

去重时分别保留至多三条连通路径，不把合并后的节点/边 ID 集合拼成一个不存在的推理链。
不会把 `has_observation` 等原关系改写成已证明的 `causes`。现有图能提供多少机制关系，仍需服务器证据审查。
该能力通过显式选项开启，原检索调用默认保持原行为。
共享节点可能汇集多个论文的引文；引用所属论文现在优先由原索引的 document→paper 映射确定，
并排除 benchmark 的全部来源文档。预检再次检查引文文档、归属论文和图路径连接是否一致。

### 2.2 先过滤证据，再按轮次重选

从原 RAG 索引和 Small KG 各检索五组吸附熵/形状/孔体积/孔径主题，建立版本固定的证据池。
各通道统一过滤：

- 原 benchmark 论文、直接引用其答案的片段及已排除来源。
- 缺少吸附熵/受限平移或转动机制的一般等温线。
- 只有数值的表格残片及缺可靠来源定位的记录。
- 缺少吸附语境的水重组、反应熵/环氧化周转段落。

保留原始引文，单独记录 HTML 清理和相关段落截取。来源中的酸位、阳离子、水及温度范围作为适用性标签，
未知条件标为未知；不自动将有酸位文献视为纯硅框架的直接证据。

第二、三轮依据已保留公式、评分/拒绝反馈及模型提出的竞争机制查询，在这个冻结池内重新排序、选择证据。
这是**冻结池内的自适应检索**，尚未实现每条轨迹按新查询重新访问完整索引。
RAG 同样更新证据，避免把反馈机会只赋予 KG。

### 2.3 三组共用变量字典和量纲审查

变量定义依据原论文方法第 4.2 节的字典，特别纠正：

- PBF：分子原子到最佳拟合平面的平均距离，描述平面性。
- Vol：吸附质分子的范德华体积。
- SPAN：以质心为中心包围分子所有原子的半径。
- GeDi：分子中两原子间的最大距离。
- lsd_f/lsd_p：最大自由球直径/自由球路径上的最大球直径。

字典只提供输入定义，不向提案模型提供本文 SHAP 排名、预测值或发现答案。
[原论文方法](https://pubs.acs.org/doi/10.1021/jacsau.4c00429)

为每个输入提供相同单位的 `NAME_ref` 和无量纲 `q_NAME=NAME/NAME_ref`。
reference 是训练行非零绝对值的中位数，只使用输入特征，不使用标签、评分/测试行。
原生 D0 仍是原始 14 项；这些符号只是公式的固定表达方式，没有增加独立信息。

在拟合前拒绝：对有量纲量取 log/exp、不兼容量纲相加、使用裸常数保护有量纲量、将未知密度单位当已知单位等。
保留原数值稳定性和训练行冗余检查。单位代数不能证明机制正确，也不能替代实际数值单位换算，
因此建议通过 reference 表达不同单位的面积/体积组合，机制仍需审查。

### 2.4 公式加入树模型

每条完成轨迹的 ANN 选择集合冻结后，额外计算：

- 原 14 项 D0 HGB＋选定公式，对比原 14 项 D0 HGB。
- 全原始输入 HGB＋选定公式，对比全原始输入 HGB。

不根据测试结果重新选公式。这回答 ANN 选出的表达式是否能迁移到强预测器；
以树模型反馈重新进行 3×3 是另一项实验，当前未实施。

## 3. 试跑设置

| 项目 | 设置 |
| --- | --- |
| 模型 | GLM-5.3-Flash，与原批次一致 |
| 三组 | Agent、RAG、KG+RAG |
| 轨迹 | 各 3 条，共 9 条，用于调试与初步检查 |
| 搜索 | 每条 3 轮，每轮 3 个候选，共 81 个候选 |
| 保留 | 每轮最多一个评分改善者，无改善保持当前集合 |
| 原生 D0 | 完整 14 项，共用原已复现基线 |
| 拟合 | 原 ANN、4000 epochs、seed 3，原统一初始化修正 |
| 数据 | 复用原训练 2361 / 评分 591 / 外层测试 738 |
| 证据池检索 | 每个主题、每个来源最多 160 个候选 |
| 知识预算 | 每轮最多 120 个候选、32 条证据、每论文最多 4 条、32000 词法 token |
| 模型输出 | 三组均为 16000 token；明确截断时自动扩至 32000 重试 |
| 计数 | 包括实际传入的关系、条件和引文的 JSON 文本 |

根据用户要求，原本 4000/4500 的上下文/输出限制已放宽。单条引文、图边支持文字和科学条件
不再按字符数截短；保留完整选定片段。文件路径、校验值等记录管理字段不进入科学上下文。
达到上下文上限时跳过完整证据条目，避免截掉限定条件；记录被跳过数量和条目上限是否触发。
配置文件通过 `--config` 实际用于证据构建与三组任务，同一证据池必须使用同一预算配置。
这些是实验预算，不是模型的官方上下文规格。实际 API prompt/completion/reasoning 用量一并保留。

长度不足时不使用无关材料填充。记录实际 token、是否接近上限；目前只实现统一上限，
**尚未声明实际上下文长度严格匹配**。正式比较前需要检查是否仍存在明显长度差异。

原外层测试的结果已被查看，本轮将它标记为开发诊断，不作为新的盲测证据。
大规模版本选择优先根据评分、证据质量和机制错误率，不能按测试排序反复调方法。
正式 NMI 结果还需要预先冻结且未参与方法选择的分组泛化或新增数据评估。

## 4. 图结构消融与试跑后的判断

已提供 `--graph-view text`：同一图证据输出节点事实和关系文本，取消显式路径组织。
这只是一个可运行接口，消融尚未执行。对照中要审查选择的事实、实际长度和成本是否相当。
后续还需关系打乱和多个划分/拟合种子的比较。

试跑先判断：

1. KG 上下文是否具有相关关系、明确条件和可靠出处，而不是只有连接编号。
2. 有效候选率、单位错误、冗余、失败原因是否改善。
3. 提案和保留公式是否实际引用、正确使用 KG 关系，引用次数不能替代因果贡献验证。
4. 评分收益、冻结公式的树模型收益、实际 token/拟合成本如何变化。

九条试跑不足以证明 KG 稳定最好。若没有优势，应依据机制与接口审查继续排查，保留结果。
