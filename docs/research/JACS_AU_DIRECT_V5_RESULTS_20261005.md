每条先平均五个 seed 相对同 seed D0 的 MAE 降幅，再平均十条生成轨迹。D0 五 seed 的 MAE/R 均值为 0.574314335。MAE 均值与平均百分比的分母顺序不同，因此不将均值比值替换预声明主指标。

| Agent | 0.569833837 | +0.776041% | [0.014098, 1.495056]% | 21 |

| 差值 | 均值/pp | 区间/pp |

## 三个影响结果的重要事实

### 1. 一个确实存在的接口不兼容，不是缺失科学假设

`proxy_assumptions` 模型输出经常是非空字符串列表，里面有具体代理限制和迁移条件。旧 `validate_candidate()` 只接受字符串，对列表抛出 **Missing candidate text: proxy_assumptions**，错误描述具有误导性：这些案例有文本，只是容器类型不同。

旧格式恢复会锁定原 `proxy_assumptions` 的整个 Python 值；模型将列表转换为字符串后，逐值比较又将其拒绝为科学修订。这让本来可通过本地表示适配解决的问题消耗恢复请求并丢失槽。不能把所有改稿都认定为无害格式变化：有的恢复也改了真实科学字段，因此仍需严格保全。

| 方法 | 首次列表类型失败 | 仅保序换行拼接后通过原结构校验 | 原提出阶段失败总数 | 技术失败总数 |
| --- | ---: | ---: | ---: | ---: |
| Agent | 3 | 2 | 4 | 5 |
| RAG | 9 | 9 | 9 | 4 |
| KG | 9 | 8 | 10 | 4 |
| 合计 | 21 | 19 | 23 | 13 |

21 个案例中，13 次恢复仅在受锁字段 `proxy_assumptions` 上发生值变化（包括类型/文本变化）；另有案例同时改变其他字段，不能全部放行。7 个恢复仍返回列表，继续遭到字符串校验拒绝。19 个“适配后通过”只是 **schema 成功**，并非执行检查、物理检查或 ANN 成功；另外两例仍有真实 schema 问题：Agent-8/R3 的物理 claim 类别非法、KG-4/R1 的 hold_fixed 声明非法。

例如 [RAG-10/R1](../../research/reports/jacs_au_direct_v5_20261005/complete-server-results/generation/rag_agent-replicate-10.json) 的原公式 `GeDi/lsd_p` 附带四条非空代理假设，却因列表类型失败；这是格式接口拒绝，不证明公式无收益。其他成功轨迹上的同式正收益不能直接移植到这个不同组合/轮次。

已新增 [无损接口适配器](../../research/src/catalysis_research/experiments/jacs_au_direct_interface.py)：对非空字符串列表保序逐项换行拼接，只在派生副本中改变表示，原始响应保留，不调用 LLM、不换公式、不改写假设内容；缺失/空内容仍拒绝。两项回归通过，包括科学字段和原输入不变、坏科学声明不因适配而通过。**它尚未接入已冻结的 20261004 科学 release，也没有用于改写本批定稿或重算主排名。**

该不兼容对知识组影响更多，是本批系统比较的重要实现干扰。它不是网络/API故障，也不是知识机制无效的证明。当前不能定量声称修复会恢复多少 MAE，或保证 RAG 超过 Agent。

例如 seed=3 时 Agent 均值最高，seed=17 时 RAG 均值最高。两 seed 显示希望排序，但不能挑它们；主结果仍平均全部五 seed。各方法轨迹内部 seed 增益标准差平均约 2.81–2.97 pp，远大于 KG−Agent 的 0.150 pp 均值差（这是两层波动的描述，不能混当独立重复）。

标签无关的符号/仿射规范化已经修正等价表示任意翻号的问题；它不保证 ANN 对任意非线性变换、不同特征组合或不同初始宽度都获得同样收益。

### 3. 目前主要发现简单几何代理，图机制组合的独有收益尚未得到证据

完整公式保存在全部 30 轨迹及 90 槽文件。多数成功表达是分子几何量与 Df/Dif 的比、比的 log/exp/有界变换。KG 成功式主要使用 GeDi、Vol、SPAN、Df/Dif 与 LabuteASA；没有成功转动惯量组合。不能把这些普通几何式自动记作图产生的独有新机制。

几个具体最终组合：

| 轨迹 | 最终直接加入公式 | 五 seed 平均降幅 |
| --- | --- | ---: |
| KG-9 | `q_SPAN/(q_SPAN+q_lsd_p)` | +2.902813% |
| KG-8 | `q_Vol**(1/3)/q_lsd_f` | +2.366264% |
| KG-4 | `GeDi/lsd_f`；`SPAN/lsd_p` | −2.107655% |
| RAG-7 | `exp(-q_SPAN/q_lsd_p)` | +1.448710% |
| RAG-5 | `(GeDi/lsd_f)**2` | −1.214299% |
| Agent-4 | `log(1+(q_GeDi/q_lsd_f)**2)`；`q_Vol/(q_Vol+q_AV+0.02)` | +2.200377% |

KG-5、KG-6 与 RAG-8 最终都只加入 GeDi/Df 的等价表示，均值均为 +0.307227%。Agent-2 的 `GeDi/(GeDi+lsd_f)` 与 RAG-10 的 `lsd_f/(lsd_f+GeDi)` 互为 1−f，在新规范化后五 seed 得到相同得分，均值 +0.801322%。这种跨组重合说明收益不是方法标签独有；语法上每组十个不同公式序列，不等于十个不同机制。

KG-4 的负收益组合是直接加入协议的真实结果，不能撤去第二项后评分择优；本批未评分中间组合，也不能仅凭最终分数判断是哪一项造成损失。4 个成功追加槽存在错误的结构化极限声明，均独立标为科学一致性失败并保留数值评分：Agent-1/R3、RAG-2/R1、RAG-3/R3、KG-7/R2。可执行并不等于机制已证实。

## 为什么比旧 V4 约 7% 小

新旧协议同时改变了候选择优、每轮提案数量、知识进入时机、训练标签反馈、RAG 同事实控制、表示规则与拟合 seed 数。旧 V4 可以从三个候选中选择改善者并拒绝负收益，新协议直接加入一个合法定稿。因此不能将约 7% 与约 1% 的差直接归因于模型/知识变差，也不能将新旧批次当作单一修复的因果消融。接口失败造成实际追加只有 54/90，是额外影响，但贡献大小未知。

所有 237 次科学 API 尝试均记录 finish_reason=stop，没有截断或失落 usage；保存的 237 个响应 ID 不重复。每组首轮十份完整结构化答案均不同。输入缓存 token 共 106624/2246736，约 4.75%；这些记录没有显示整份回复被缓存成同一答案，但不能据此保证服务端不存在其他缓存。没有证据将本批低收益归因于输出 token 上限。

## 下一步固定候选消融与公平验证

先完成接口契约修复和已保存原始对象的固定候选审计，再扩大新生成重复。以下方案不修改本批 ITT 主结果：

1. 冻结全部 90 个原始首次响应与对应原历史前缀，比较原接口和无损 list/string 适配。所有模式、成功/失败、正/负候选都纳入；不调用 LLM 再生成公式，不选择对 KG 有利案例。19 个 schema 成功案例还需相同的训练特征执行/定义/导数检查，不能把 schema 通过当作追加成功。
2. 技术 metadata 修复与科学修订分开：精确定义角色可依据公共字典纠正，公式及假设不替换；缺失真实科学内容、不合法 hold_fixed、非等价换代理/表达仍按失败处理。相同预算和规则应用三组。
3. 若做静态冻结候选组合 ANN 评分，所有三组十条组合使用全部五 seed、同 D0、同表示和显式失败政策。必须命名为静态候选接口消融：补入旧失败槽后，旧后续公式的提示历史本来会变化，它不是重新生成的三轮真实轨迹，不能宣称修复后的闭环方法排名。
4. 单独冻结新 execution revision，将接口适配明确接入后重新运行三组 fresh、无标签、每轮一个、三轮直接追加、各十条或预声明更多重复。保留所有失败/负值，不按希望排序决定运行次数或选 seed。
5. 独立检验同事实 flat/graph 的增量；若加入真实路径搜索工具，平铺组获得等价事实或单列工具组件收益。新分组划分须重新发现并重算训练参考，未开发查看的新数据才可称独立评估。

本次没有启动追加 API/ANN 实验，没有补分或删除失败，没有重新选 seed；只完成全量取回、零调用审计和可复核接口适配器。旧 V4 与本批数值均保留。
