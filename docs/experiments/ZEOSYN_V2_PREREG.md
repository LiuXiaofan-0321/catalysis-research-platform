# ZeoSyn V2 预注册（草稿）

状态：**草稿，未冻结**。标为 “TO BE CONFIRMED” 的事项确认之前，`run_zeosyn_v2.py freeze` 会拒绝冻结，测试集评估也无法运行。冻结时，本文件的 SHA-256 会写入 `configs/experiments/zeosyn-v2.json`；之后本文件只要有任何改动，测试集评估就会失败。

方案：[ZEOSYN_V2_PLAN.md](ZEOSYN_V2_PLAN.md)。开发日志：[ZEOSYN_V2_ITERATIONS.md](ZEOSYN_V2_ITERATIONS.md)。

## 1. 假设

- **H1**：Agent 相对公开 D0 有提升。
- **H2（主假设）**：KG 相对 Agent 有提升。
- **H3（次要）**：KG 相对 RAG 有提升。

## 2. 数据与划分

- ZeoSyn 原始文件逐字节固定（`data/zeosyn/`，载入时校验 hash），D0 为原论文的 43 列，预测模型为原生 RandomForest（100 棵树）。
- 测试集：与 V1 相同的按 DOI 分组划分（种子 20261007，20%）。V1 在这个测试集上已经评估过一次，V2 的所有设计调整都只在开发集上进行。
- 开发集：在外层训练集内部再按 DOI 分组划分（种子 1，20%）。开发阶段同时排除测试集论文和开发验证集论文。

## 3. 实验组

| 组 | 知识来源 | 输入 |
|---|---|---|
| agent | 无 | 原始输入 |
| rag | 全文检索（47,440 个合成相关文本块，评估论文已排除） | 原始输入 |
| kg | KG 汇总事实（实体名称、关系、实验数和论文数） | 原始输入 + 文献特征（kg_*） |
| kg_shuffled | 与 kg 相同，但 OSDA 与实验的对应关系被打乱（种子 20261009） | 原始输入 + 打乱后的文献特征 |
| 只加文献特征（诊断） | 不用 LLM，D0 + 全部文献特征 | — |
| kg_flat（可选） | 与 kg 相同的实验逐条列出，不做汇总 | 原始输入 + 文献特征 |

- 每组轨迹数：**TO BE CONFIRMED**（默认 10；如果开发集上噪声偏大，改为 15）。
- 是否加入 kg_flat：**TO BE CONFIRMED**（默认不加）。
- 所有组的流程相同：每轮三步（选研究因素并自拟检索词 → 检索 → 提出描述符），共 3 轮，不给标签反馈，技术修复最多 1 次，失败的槽位保留不补。模型为 GLM-5.3-Flash，thinking 开启，reasoning_effort high，temperature 0.2。
- 提示词版本以冻结时的 commit 为准。

## 4. 防泄漏

- 评估论文从 RAG、KG 事实和文献特征中全部排除；每条配方的文献特征另外排除它自己所在的论文。
- 敏感性分析：时间截断版（只用更早发表的论文），以及外部版（排除全部 ZeoSyn 论文）。时间截断作为敏感性分析还是主分析：**TO BE CONFIRMED**（默认作为敏感性分析）。
- 直接答案审计：在协议冻结之后，统计测试配方中“KG 给出的最常见框架等于真实标签”的比例，并在论文中披露。

## 5. 评价指标与判定标准

- 主指标：**TO BE CONFIRMED**（默认准确率，与原论文和 V1 一致；macro-F1 和 balanced accuracy 为次要指标）。
- 统计单位：生成轨迹，5 个 fit seed（3、7、11、17、23）先在轨迹内平均；每个描述符组合都与同一 seed 下的 D0 配对比较。
- 判定 H2：KG − Agent 的 95% bootstrap 区间（10,000 次重采样，种子 20261009）下限 > 0。
- 判定 H1：Agent 相对 D0 增益的 95% 区间下限 > 0。
- H3 及其他对照（KG − 打乱 KG、打乱 KG − Agent）只报告区间，不作为主结论。
- 所有轨迹都计入，包括失败、零追加和负收益的轨迹。

## 6. 机制分析与敏感性分析（预先指定）

- 分层：该配方的 OSDA 是否被 KG 覆盖；该 OSDA 在训练集中是少见还是常见（少见定义为少于 10 条训练配方，包括从未出现）；以及不含 OSDA 的配方。
- 只加文献特征（不用 LLM）的诊断组，按同样的方式分层。
- 敏感性：时间截断版和外部版文献特征（重新评估 KG 组冻结的公式）；HGB 预测模型（1 个 seed）。
- 检索质量：GLM 对 RAG 和 KG 证据的相关性判断，目标 ≥ 70%。
- 假设质量：使用了文献特征的槽位比例、引用了证据的槽位比例、研究因素的多样性。
