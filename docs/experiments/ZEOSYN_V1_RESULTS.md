# ZeoSyn V1 结果与机制分析

协议：[ZEOSYN_V1.md](ZEOSYN_V1.md)。原始记录：`results/zeosyn_direct_v1_local_20261008/`（2026-10-08，台式机运行，代码 `3bfc543`）。本文是对这批结果的如实记录。V2 方案的动机见 [ZEOSYN_V2_PLAN.md](ZEOSYN_V2_PLAN.md)。

## 结果

D0 测试准确率 43.31%（按论文 DOI 分组划分，4,405 条测试配方）。三组各 10 条轨迹，90 个槽位全部成功加入描述符。

| 组 | 相对 D0 的准确率增益 | 95% 区间 | 负收益轨迹 |
|---|---:|---|---:|
| Agent | **+0.54 pp** | [0.38, 0.71] | 0/10 |
| RAG | +0.10 pp | [−0.05, 0.26] | 2/10 |
| KG+RAG | +0.17 pp | [−0.02, 0.34] | 4/10 |

- 组间差值（97.5% 区间，与 V1 报告一致）：RAG − Agent −0.44 pp [−0.70, −0.17]；KG+RAG − Agent −0.37 pp [−0.66, −0.10]。两组知识条件都**显著低于** Agent。KG+RAG − RAG：+0.06 pp，区间跨 0。
- macro-F1 的增益更小（Agent +0.08，RAG −0.63，KG+RAG −0.32），换用这个指标并不能让提升变大。
- 开发集复查（训练集内部按 DOI 再划分，测试集未动；为适应内存限制，RandomForest 减为 60 棵树、3 个 seed）：Agent +0.09，KG+RAG −0.32，RAG −0.43 pp，排序与测试集相同。各轨迹在开发集和测试集上的增益相关系数只有 0.21，单条轨迹的结果噪声很大。

## 机制

1. **固定检索词决定话题，知识组被带向同一类公式**。每轮 20 条知识组轨迹都收敛到同一类公式：第 1 轮是阳离子/Al 电荷平衡，第 2 轮是 `F/sda1`，第 3 轮是 Arrhenius 型的时间-温度项。第 2 轮里，20 条轨迹全部引用了同一段关于 HF/OSDA 比的文字。
2. **检索质量低**。例如第 1 轮的 9 条 RAG 结果中，只有约 3 条与 OSDA 结构导向直接相关。
3. **KG 结构对模型不可见**。提示词里只有哈希 ID 和孤立的句子片段。
4. **提示词要求“依据证据”**。知识组因此按检索到的内容构造描述符：18–20/30 个提案自评为“新组合”，Agent 只有 9/30。证据使提示词变长约 4 倍，但推理 token 数没有变化。
5. **没有信息通道**。新描述符只能重组已有输入，提升上限约 1 个百分点，而且所需的知识都是教科书常识。

需要说明一点：单看一个描述符，知识组那几类公式本身并不比 Agent 的差（开发集上，单个描述符的增益在 −0.4 到 +0.9 pp 之间，与噪声同量级）。差距体现在三个描述符组合在一起之后。

## 结论

把检索到的证据原样塞进提示词，会锁定话题、让提案同质化，使知识条件不如不给知识。知识要发挥作用，需要模型自主决定查什么、证据以可读的结构化形式呈现，并且要有一个让新信息进入模型的通道。这些都是 V2 的改动内容。
